About Database systems

MOST IMPORTANT POINT TO KEEP IN MIND BEFORE READING THE FOLLOWING PAGES

Changes in the database metrics are happening at the same time in which the change in latency happens. There are no metrics changing at an earlier point in time which will help us predict changes in latency. This is the main challenge that we face regarding prediction.

Update (5th May, 2021): The above comment was made when we were using only metrics coming from a given component to make predictions about latency of that component. Now, we have a better understanding about RCA etc and we realize that we should look at interaction between components. When we do that we will see more situations where one components shows changes in behavior ahead of other components.
