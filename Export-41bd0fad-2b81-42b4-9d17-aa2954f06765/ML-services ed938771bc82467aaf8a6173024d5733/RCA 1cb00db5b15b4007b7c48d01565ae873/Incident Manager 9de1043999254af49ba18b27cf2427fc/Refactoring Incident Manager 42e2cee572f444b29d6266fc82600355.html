Meeting Notes 2022-08-02 16H-17H

The architect for a better IM:

Qualification Service would be a new service writen in python to analyse the raw ml output to tell if an anomaliy can be qualified as important anomaly. Qualification Service will feed data to IM.

Important Anomaly can trigger/extend an incident

Correlation Services would be a new service which provides correlation topology infomation for IM in order to determine an anomaly is related to an existing incident or not. Currently we do not touch this and it is done by IM itself by using a simple algorithm.

RCA Services would be a new service which read an entire incident’s data and output the Root Cause.

Incident manger will get anomaly data from Qualification Service

Incident manger will call the Correlation Services with a new anomaly to determine: create or extend an incident.

Incident manger will call the RCA Services with an entire incident to find the root cause of an incident.

What is currently worked on by @dengke li and @Valentin Lapparov is the Qualification Service.

Qualification Service would read default configuration, global configuration and component specific configuration in mongodb. A mongodb collection called integrationmetricsfilters is configured from frontend’s integration page.
