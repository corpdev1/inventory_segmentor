Setting up Elastic Apm Server

https://www.elastic.co/guide/en/apm/server/current/installing.html

https://www.elastic.co/guide/en/apm/server/master/running-on-docker.html

On a ec2 machine

  1. Download package
curl -L -O https://artifacts.elastic.co/downloads/apm-server/apm-server-7.12.1-amd64.deb
sudo dpkg -i apm-server-7.12.1-amd64.deb

2. Configure apm server to send to kafka in /etc/apm-server/apm-server.yml (Configuration is similar to metricbeat and filebeat) 3. Run

sudo -u apm-server apm-server -e

Instrumenting Microservices

Golang (catalogue, user, payment)

Microservices use gorilla for http server. So we ll use apmgorilla to wrap the http handler

https://www.elastic.co/guide/en/apm/agent/go/master/builtin-modules.html#builtin-modules-apmgorilla

Steps:

  1. import module
"go.elastic.co/apm/module/apmgorilla"

2. wrap the router returned by gorilla.mux

apmgorilla.Instrument(router) 
// or
router.Use(apmgorilla.Middleware())

3. In DockerFile, indicate the apm server endpoint

ENV ELASTIC_APM_SERVER_URL=http://ec2-35-180-199-45.eu-west-3.compute.amazonaws.com:8200

Java (carts,order)

https://www.elastic.co/guide/en/apm/agent/java/current/setup-javaagent.html#setup-javaagent-download

  1. Download elastic apm java agent jar file
  1. Add as argument to java running command
-javaagent:./elastic-apm-agent-1.23.0.jar -Delastic.apm.server_url=http://ec2-35-180-199-45.eu-west-3.compute.amazonaws.com:8200

NodeJS (front-end)

https://www.elastic.co/guide/en/apm/agent/nodejs/master/intro.html

front-end ms uses express js

  1. Set env variable
ELASTIC_APM_SERVER_URL=http://ec2-35-180-199-45.eu-west-3.compute.amazonaws.com:8200

2. Add this line to the code (at the beginning)

var apm = require('elastic-apm-node').start()
