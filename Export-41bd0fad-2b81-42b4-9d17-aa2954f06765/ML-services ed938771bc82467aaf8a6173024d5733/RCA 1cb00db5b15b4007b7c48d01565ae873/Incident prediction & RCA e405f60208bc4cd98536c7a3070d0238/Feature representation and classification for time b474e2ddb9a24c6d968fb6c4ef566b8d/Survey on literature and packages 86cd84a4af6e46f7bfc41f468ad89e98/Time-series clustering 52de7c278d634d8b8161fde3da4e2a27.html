Introduction

Time-series clustering algorithms fall into two categories. Whether similarity measures are defined:

  • Directly on input (raw) data.
  • On the features extracted from input data.

The first approach is based on distance measures like Euclidean distance, cross-correlation, DTW etc. Even though approaches like DTW and cross-correlation allow flexibility in matching corresponding regions between two time-series, there are limits to how different the two time-series can be. The second approach considers the time-series instances to be generated by underlying models or probability distributions. This is what we need to cluster time-series according to categories like sparse, step etc. Other advantages of feature based methods: Robust to the impact of noise and outliers. Reduces the dimensionality of the data, to the number of features. In the case of distance based approaches the dimensionality is directly related to the length of the time-series. Feature based methods can be of two types:

  • Two stage approaches that cluster after extracting features.
  • Approaches that jointly optimize the feature learning and clustering.

Non-DL approaches

DTW, Cross-correlation, Global alignment kernel

  • DTW requires the samples to be samples at the same time instances across all the time-series.
  • DTW can handle distortions in amplitude (scaling) and phase (shifting).
  • Cross-correlation (k-shape) can also handle such distortions.
    • k-Shape: Efficient and Accurate Clustering of Time Series, Paparrizos and Gravano, SIGMOD 2015, 333 citations.
    • https://github.com/johnpaparrizos/kshape
  • https://tslearn.readthedocs.io/en/stable/gen_modules/tslearn.clustering.html#module-tslearn.clustering
  • Also, refer this section on alignment.

Cluster based on features generated by TSFresh

  • A huge set of features can be computed using TSFresh.
    • 787 features in our experiment with 249 time-series.
  • Deciding which ones to use for clustering needs more thought.
    • https://github.com/blue-yonder/tsfresh/issues/678
    • By referring to papers using statistical features for time-series clustering, we can figure out what features can be tried.

Papers about statistical features extracted from time-series

Characteristic-Based Clustering for Time Series Data, Wang et al, Data mining and knowledge discovery 2006, 512 citations.

  • Global measures describing the time series are obtained by applying statistical operations that best capture the underlying characteristics: trend, seasonality, periodicity, serial correlation, skewness, kurtosis, chaos, nonlinearity, and self-similarity.
  • https://github.com/njfritter/Characteristic-Based-Time-Series-Clustering

Feature-Based clustering for electricity use time series data, Raesaenen and Kolehmainen, International Conference on Adaptive and Natural Computing Algorithms 2009, 84 citations.

  • 7 features: In this study, features were extracted from the raw hourly measured electricity use data using window of one week i.e. 168 data rows (hours). We extracted 7 features from each customer's data. The features extracted were; mean, standard deviation, skewness, kurtosis, chaos (Maximal Lyapunov exponent), energy (the sum of the squared discrete FFT component magnitudes of the signal, normalized by the window length) and periodicity (Discrete Power Spectrum (periodogram): the most powerful frequency value).

Feature-based time-series analysis, Ben D. Fulcher, Book chapter in Feature Engineering for Machine Learning and Data Analytics 2018, 64 citations.

https://lemaizi.com/blog/time-series-clustering-the-curse-of-dimensionality/

  • Trends, means, maximum values on certain days or entropy for example.
