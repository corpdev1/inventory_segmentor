Note: Data from May 31st and later was used for this analysis. This is because before this date some components had aggregation switching between 60 seconds and 10 seconds. Many of the metrics for which optimal weights have been assigned (look here) are of value zero after May 31st. In the below tables the dates from which they become zero have been noted.

Note: (15/6/2021) The weight for walter will be adjusted in a week or so after enough reliable data. For now, inconsistencies in walter's weights are ignored.

Generally, all the network metrics of a given component behave the same way. Exceptions: nodehyperion-server_hyperion-server - docker#network#in#bytes-no_subject behaves like a noisy version of Class 5. However, the other three networks behave similarly.

pythonkoios_koios_tasks - docker#network#in#bytes-no_subject behaves like Class 2, while docker#network#in#packets-no_subject, docker#network#out#bytes-no_subject and docker#network#out#packets-no_subject are noisier and hence, Class 3. Among the latter three, docker#network#out#bytes-no_subject and docker#network#out#packets-no_subject behave similarly and when seen over a period of two weeks, we can notice that apart from random spikes like Class 3, they also repeatedly take values from a fixed range (like Class 5). More details below.

Check here for representative time-series of the various classes. To recap the class descriptions are as follows:

Class 2 - Occasional spikes with considerable distance between the spikes and limited noise/small spikes between the larger spikes.

Class 3 - Similar to Class 2 (Occasional spikes with considerable distance between the spikes) but more noise/small spikes between the larger spikes.

Class 5 - Regularly occurring spikes, with the spikes taking only a limited set of values.

Class 10 - Densely occurring spikes, with the values being random. There is considerable distance between the spikes, thus leading to anomalies detected by MAD.

Class 14 - Densely occuring spikes, with the values being random. The distance between the spikes is lesser compared to Class 10, thus less anomalies detected by MAD.

In other words, an important difference between Class 10 and Class 14 seems to be the presence of wider gaps between the spikes in the case of Class 10. The spikes in Class 14 are happening more densely. This leads to more anomalies being detected in Class 10. Compare pythonkoios_koios-worker and pythonhyperion-client-plages_hyperion.
