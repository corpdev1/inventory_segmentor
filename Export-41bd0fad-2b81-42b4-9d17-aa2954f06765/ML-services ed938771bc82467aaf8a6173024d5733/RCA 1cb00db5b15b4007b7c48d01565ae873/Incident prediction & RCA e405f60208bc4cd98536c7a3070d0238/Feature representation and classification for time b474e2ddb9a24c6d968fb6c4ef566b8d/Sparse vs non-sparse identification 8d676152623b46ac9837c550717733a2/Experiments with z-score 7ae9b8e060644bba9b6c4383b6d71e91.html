Experiments with z-score

@Hariprasad Kannan wrote:

The main take-aways are:

  • Z-score based on uniform moving window average over a window of size 30K leads to a time-series that looks similar in shape to the original time-series. If the original time-series has a trend, the z-score time-series also has it.
  • Z-score based on exponentially weighted moving window average over a window of size 30K leads to a time-series for which trend has been removed to some extend.
  • However, the division by standard deviation to compute the z-score leads to a time-series in which spikes get suppressed. This leads to misses.
  • Thus, another experiment has been done where we only subtract out the mean (computed by exponentially weighted moving average).

These experiments were done on the following components of Affluences:

The main motivations to try z-score based on uniform window and exponentially weighted window is to get a better idea about how MAD sees the time-series.

The seven algorithms in Skyline are:

  • median_absolute_deviation
  • first_hour_average
  • stddev_from_average
  • stddev_from_moving_average
  • mean_subtraction_cumulation
  • least_squares
  • histogram_bins

Of these, stddev_from_average and mean_subtraction_cumulation “see” almost similar view of the time-series: uniformly weighted window.

stddev_from_moving_average sees exponentially weighted window.

Need to ask Valentin Lapparov, whether we have to test the view of median_absolute_deviation: subtracting the median from the time-series.

So far, the following have been tested:

  • z-score based on moving window of size 30000 (same setting as MAD).
  • z-score based on moving window of size 360.
  • z-score based on exponentially weighted moving window with the same settings used in MAD.

The first approach doesn’t transform the time-series apart from making it zero-mean and unit variance. This doesn’t affect the output of sparse vs non-sparse identification. Since, the window size is big, it doesn’t compensate for the trend in the time-series.

The second experiment was done to see the effect of the window in adjusting for the trend.

The second and third approaches are good at removing the trend from the time-series. For e.g., sparse time series with daily period in the low values are now without that daily periodicity of the low values and can be more accurately identified as sparse.

Note: The test with window size of 360 was done to get a better intuition about z-score computed from moving windows. We can use the exponentially weighted approach to remove trend, since, the same setting is used by MAD also.
