About named entity recognition (NER)

In NLP, named entities are phrases/chunks-of-text that contain the names of persons, organizations, locations, countries etc. Named entity recognition (NER) is about parsing unstructured text to not only detect entities but also classify them into specific categories. Also, the categories are pre-defined.

NER models the context in which the entities occur, in order to label new instances of entities of unseen values.

Named entity recognition requires labelled data. At a high level, each token has to be labelled as belonging to a particular category or not belonging to any category. In more detail, tokens can be labelled as beginning (B) token of a category, inside (I) token of a category, ending (E) token of a category, outside (O) any categories.

Based on the observations so far, semi-supervised and unsupervised techniques are building a small set of entity name-entity value pairs and propagate this information to the entire training data-set. Need to understand more about language independent NER.

General architecture of NER systems:

  • Modeling the tokens: word embeddings; character embeddings + character based word representation (CNN/LSTM); other features (POS, capitalization.
  • Modeling the sequential relationship (BiLSTM).
  • Inference layer (soft-max or CRF).

Note: Character based representation is important for modeling special tokens like IP address etc. Inference based on CRF models sequential relationship better and leads to better results.

One possible way to generate character embedding: Randomly initialized a lookup table with values drawn from a uniform distribution with range [−0.5, 0.5] to output a character embedding of 25 dimensions (from "Named Entity Recognition with Bidirectional LSTM-CNNs", Chiu and Nichols, 2015).

Take-aways

  • NER could be seen as part of the bigger topic of information extraction (IE) from unstructured text.
    • https://nanonets.com/blog/information-extraction/, https://www.ontotext.com/knowledgehub/fundamentals/information-extraction/
    • Information Extraction: Distilling structured data from unstructured text, Andrew McCallum, ACM Queue 2005
      • https://en.wikipedia.org/wiki/Unstructured_data
    • The topic of unstructured text is worth exploring further. Even though logs are claimed to be semi-structured, they are borderline unstructured.
      • There are many papers and time is needed to see what approaches are being taken for unstructured text. For e.g., "A Comparison of Dimensionality Reduction Techniques for Unstructured Clinical Text", Halpern et al, ICML workshop 2012, shows that unsupervised Latent Dirichlet Allocation (LDA) is competitive with more advanced methods for representation dimension of 50 or more. Topic models are good at capturing document level properties.
  • Character based embedding is very important to deal with special tokens like IP addresses, date-time strings, timestamp, IDs etc. Character based embedding could be useful for us in other projects.
    • There is no word embedding available for these tokens. Refer, Neural architectures for Named Entity Recognition, Lample et al, arxiv 2016.
  • Header information in logs is in the form of small independent chunks of information (date, IP address, level string) which are not part of a longer text sequence. Generally, NER techniques model the sequential context in which a token appears.
  • NER could be one of the earlier steps before other tasks like understanding relationships for RCA (refer SoftNER paper).
  • For unsupervised/semi-supervised approaches:
    • Look for standard symbols like '=', ':' etc and identify key-value pairs.
    • Keywords noticed while looking for unsupervised/semi-supervised NER: bootstrapping, language independent NER, general NER (Alfonseca and Manandhar).
    • Other promising references for obtain weak supervision (from SoftNER paper):
      • Snorkel: Rapid training data creation with weak supervision, Ratner et al, VLDB 2017.
        • LOOKS PROMISING: https://www.snorkel.org/
      • Code search intent classification using weak supervision, Rao et al, arxiv 2020.
  • For practical purposed work with a pre-defined set of semantic categories. Unsupervised techniques also depend on user feedback to label automatically identified categories.

Experiments

The tests with both the packages behave similarly. We are observing that the algorithm is very much sensitive to the position of the entity with respect to the other entities. Thus, even if the content of the entity is noisy, it could still be recognized if it is in a predictable position. We see much poorer performance when the positions of the tokens are shuffled.
