Building topology from istio data

  • First, we need to monitor Istio with metricbeat module https://www.elastic.co/guide/en/beats/metricbeat/current/metricbeat-module-istio.html
  • Istio provides data as transaction, hence we need a tool to build the service map (toplogy) from these transactions. We chose Kiali https://github.com/kiali/
  • Istio saves transactions data (telemetry data) in a prometheus instance in a pod in the same cluster. Kiali collects that data and shows it on UI
  • We embed Kiali in minima https://github.com/kiali/kiali#embedding-kiali
  • We need to figure out persistent storage of this data. Could be in a DB (Dgraph for eg) or ES
