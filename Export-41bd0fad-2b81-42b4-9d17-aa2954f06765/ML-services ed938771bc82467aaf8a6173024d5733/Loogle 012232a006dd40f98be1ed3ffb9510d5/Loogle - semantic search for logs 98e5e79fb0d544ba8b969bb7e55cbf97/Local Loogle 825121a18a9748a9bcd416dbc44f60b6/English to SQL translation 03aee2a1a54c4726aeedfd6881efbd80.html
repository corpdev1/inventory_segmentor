As you can see, the NLQs are not explicit and resemble Google queries, which is the expected from the users. For example: 

NLQ: opendistro connection refused
SQL: SELECT * from {index} WHERE (componentID like '%opendistro%' OR message LIKE '%opendistro%')  AND (message LIKE '%connection%refused%' OR message LIKE '%refused%connection%') order by @timestamp desc
