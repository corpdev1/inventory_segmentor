GPT3-based features

Note: examples bellow are not fine-tuned, fine-tuning would greatly improve performance

RCA enrichment

fine-tune it on blogs and Sackoverflow per theme, like:

  • how to monitor mysql
  • how to optimise kubernetes
  • how to troubleshoot kafka effectively
  • etc

and then use it for RCA messages. Example, when there is an issue with mysql, give the context in prompt and it gives you the RCA and suggestion to resolve

Semantic search

  • Semantic search in logs
    • fine-tune it on datasets of logs (maybe a careful sampling is needed)
    • you can then ask for summary of what is going on
    • you can ask if there are issues, abnormal logs etc
    • or you can just search for info, like

    “when was the first connection from IPx to rabbitmq?”

    Note:

    • semantic search can be for daily usage, on limited number of logs
    • or a specific tool for postmortem analysis, on large historic data, where user can ask questions like: who made the first connection? what time was the first error? did the error impact mysql?

  • General semantic search
    • fine-tune it on datasets containing description of topology, technologies, changes, logs, metrics etc
    • in addition to fine-tune it on stackoverflow, blogs etc
    • you can then ask any question about the infra
    • of course this helps for RCA as well

What-if analysis: risk management

  • fine-tune it on datasets containing description of topology, technologies, changes, logs, metrics etc
  • in addition to fine-tune it on stackoverflow, blogs etc
  • you can then ask what-if questions (eg, what would happens if I push this new docker image?)
  • of course this helps for RCA and general search as well

Idea

  • the idea is that gpt3 already has a vast amount of general knowledge about IT stuff “general domain knowledge”
  • then we train it on data from a specific client: notion, technical doc, config files, code if possible, etc, this is “client-specific domain knowledge”
  • then we train it on data from a specific client on a specific task, like finding root cause for error logs, this is “task-specific domain knowledge”

Trained on the 3 types of data, gpt3 would achieve great perf
