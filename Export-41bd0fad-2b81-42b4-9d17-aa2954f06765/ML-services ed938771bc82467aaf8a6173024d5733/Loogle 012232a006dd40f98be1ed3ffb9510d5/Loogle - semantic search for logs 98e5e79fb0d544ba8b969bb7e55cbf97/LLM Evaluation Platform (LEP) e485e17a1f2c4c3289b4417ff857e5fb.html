High level design and goals

  • seamlessly and easily evaluate multiple models on the same task and data sets
  • seamlessly evaluate a model on multiple data sets and with different prompts
  • version control for models, prompts, inputs, outputs and hyperparameters

Model version control

Problem

During the model development process, the developer encounters some questions:

  • which model version is used?
  • what is the diff between this version and previous?
  • what data was the model trained/fine-tuned on?
  • what is the improvement or down perf from previous version?
  • what is the prompt used for a specific output?
  • what happens if I change the temperature of the model?

Existing tools

  • https://dvc.org/
  • https://github.com/iterative/dvc - DVC is a Git-like version control system for machine learning projects. It enables data scientists and machine learning engineers to version and share machine learning models and data sets, manage experiments, and automate model training and deployment pipelines.
  • https://github.com/mlflow/mlflow - MLflow is an open source platform for the complete machine learning lifecycle, which includes experiment tracking, reproducible runs and model sharing. It is language-agnostic and supports Python, R and Java.
  • https://neptune.ai/
  • openai evals
