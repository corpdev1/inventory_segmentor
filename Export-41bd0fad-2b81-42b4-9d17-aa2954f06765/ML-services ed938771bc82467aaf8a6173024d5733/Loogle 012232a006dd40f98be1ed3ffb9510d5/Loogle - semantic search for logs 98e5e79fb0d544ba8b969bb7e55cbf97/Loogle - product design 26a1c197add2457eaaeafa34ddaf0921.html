Loogle - product design

High level design

Frontend

  • the user “chats” with Loogle about infrastructure information
  • we eventually expand from logs and metrics to configs and other sources

Backend

→ add the loogle API layer

Loogle API

2 main endpoints

  • loogle.text2sql (input:user_query_text, meta_data=target_index+schema) returns sql_query

Transform the part of index_search function until return es_query_text into an endpoint

  • loogle.summarise_logs (input: logs) returns english_summary

transform the get_logs_summary function into endpoint

For example, in js backend do

SQL_query = loogle.text2sql(”when was the last connection?”)

Logs = ES.run-query(SQL_query)

summary=loogle.summarise_logs(Logs)

Requirements

    • data management
    • model CI/CD
    • continuous testing of LLMs
