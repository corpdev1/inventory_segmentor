GCP managed services - Cloud Composer

Link to test envs: https://console.cloud.google.com/composer/environments?authuser=1&project=packetai

  • Cloud Composer is a managed GCP service packaging Apache Airflow
  • Apache Airflow is a workflow management framework based on DAGs https://airflow.apache.org/docs/apache-airflow/stable/concepts/dags.html
    • example: you have an app comprising of 3 microservices: A, B and C, each performs a particular data-related task
    • you can create a data workflow like: A >> B >> C which means, B depends on A being successful and C depends on B being successful. This DAG also shows order of tasks
  • We create a test environment (instance on gcp compute)
  • this basic DAG contains one task which prints on terminal
  • logs are categorised by source

  • Cloud Logging adds meta data to each line including its source, this is useful to separate per component. The payload is the actual log line

  • the trickiest part would be the custom logs emitted by Airflow workers (they are just pods containing custom tasks)
