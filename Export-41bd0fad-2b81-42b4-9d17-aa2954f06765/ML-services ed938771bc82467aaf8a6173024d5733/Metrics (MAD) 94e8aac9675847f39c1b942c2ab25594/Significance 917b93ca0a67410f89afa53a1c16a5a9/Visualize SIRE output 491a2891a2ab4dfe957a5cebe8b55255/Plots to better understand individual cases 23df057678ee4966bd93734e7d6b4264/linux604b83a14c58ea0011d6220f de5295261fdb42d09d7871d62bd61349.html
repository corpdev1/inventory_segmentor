sda1|system.diskio|system#diskio#iostat#read#per_sec#bytes has two high score regions. Upon further analysis the following observations have been made:

  • This time-series has almost periodic anomalous regions, with the regions occurring at almost daily periodicity.
  • There are missing samples/noise when comparing the data between ES and S3 in the first ten days of June. Thus, these two high region scores can be seen as red in the ES based plots and orange in the S3 based plots.
  • When plots are made using data after June 10th, there is consistency in the significance scores between ES and S3.
  • One can see that the deviation model is very good and correctly gives more (resp. less) score for deviation when the deviation is more (resp. less).
  • From the plots we can see that these anomalous regions are quite regular and time-between values are very close to each other. In other words, STD/mean of the time-between values is very low. See here.
  • However, a small difference in the time-between value leads to considerable difference in the relevance score. The average time-between value is 18.2679 (expressed in log scale). On June 23rd, duration score = 1.0, deviation score = 1.0, time-between score = 0.1739 leading to a relevance score = 0.7246 and the time-between value is 18.2682. On June 29th, duration score = 1.0, deviation score = 1.0, time-between score = 0.673 leading to a relevance score = 0.8910 and the time-between value is 18.2668. Check the plot based on S3 data using data starting from June 10th. It will be good to consider close to regular behavior in the time-between relevance score model.
  • In statistics literature, the ratio of the standard deviation to mean is called coefficient of variation. Some references are: 1, 2, 3, 4. An adaptation of the current model for time-between values is discussed here, which is based on coefficient of variation.
