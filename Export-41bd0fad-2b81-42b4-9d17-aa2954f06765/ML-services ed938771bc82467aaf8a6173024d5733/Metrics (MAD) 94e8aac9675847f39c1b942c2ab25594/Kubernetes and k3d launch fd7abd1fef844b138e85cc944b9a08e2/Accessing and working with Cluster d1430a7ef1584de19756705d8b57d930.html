Check pods

kubectl get pods -n argo-events

Connect to pod(go inside of pod container, inside there is disk log)

kubectl exec -it $podname -n argo-events -- /bin/bash

Connect to Affluences Cluster

aws --region eu-west-3 eks update-kubeconfig --name affluences-packetai-co --role-arn arn:aws:iam::767498580550:role/eks-admin

Connect to GetMyUni cluster

aws --region eu-west-3 eks update-kubeconfig --name getmyuni-packetai-co --role-arn arn:aws:iam::767498580550:role/eks-admin

Exit pod entered with exec

Ctrl + D

Search logs between two strings aaa and bbb

sed -n '/aaa/,/bbb/p' file

Cut first N characters of the string

cut -c 1-N

Download file from the pod

kubectl exec -n argo-events $podname -- cat $path_to_a_text_file_on_the_pod > $local_path

Describe pod

kubectl describe pod $pod -n argo-events

Update one pod with its image (image contains new code)

(delete one pod, kube will generate a new one using image)

namespace=argo-events

kubectl delete pod $podname -n $namespace

Check stdout logs of one pod

kubectl logs $podname -n $namespace

Delete one deployment (ex: delete one modelserver for lad)

kubectl delete deployment $deployment_name -n argo-events

ex:

kubectl delete deployment lad-model-10-20210331000131 -n argo-events

Connection to kube mongo from local

kubectl port-forward mongo-mongodb-replicaset-0 27017:27017 -n mongo

Connect to the stage cluster

aws --region eu-west-3 eks update-kubeconfig --name stage-packetai-co --role-arn arn:aws:iam::767498580550:role/eks-admin

Connect to elasticsearch on cluster?

kubectl port-forward $podName localPort:kubePort(9200) -n nameSpace

  • To get pod in the namespace:
    • kubectl get pods -n od-system
  • Get the first one with client in the name

Connect to mongo on cluster?

kubectl port-forward $podName localPort(27018):kubePort(27017) -n nameSpace

  • To get pod in the namespace:
    • kubectl get pods -n mongo

Same as before

Same as before

How to change environ variables which are used in a project?

  1. Make changes in flux
  1. Delete deployment: kubectl delete -f filepath
  1. Deploy new changes: kubectl apply -f filepath

Start staging cluster

  1. Go to https://eu-west-3.console.aws.amazon.com/ec2autoscaling/home?region=eu-west-3#/details/eksctl-stage-packetai-co-nodegroup-packetai-service-nodes-NodeGroup-O0VM0DCPAMH0?view=details
  1. Edit desired capacity to 5

Restart a pod

We can just delete it

kubectl delete pod $pod -n $ns

Update docker image tag for MAD

kubectl edit sts $pod -n argo-events

Connect to staging mongo with MongoDB Compass

  1. kubectl port-forward mongo-mongodb-replicaset-1 27018:27017 -n mongo
  1. Compass connection string: mongodb://root:example@localhost:27018

Delete all MAD pods

names=$(kubectl get pods -n argo-events|grep 6040|cut -d' ' -f1)
for i in $names;do kubectl delete pod $i --grace-period 0 --force -n argo-events; done

Reveal all ML secrets

kubectl get secret ml -n argo-events -o go-template='{{range $k,$v := .data}}{{"### "}}{{$k}}{{"\n"}}{{$v|base64decode}}{{"\n\n"}}{{end}}
