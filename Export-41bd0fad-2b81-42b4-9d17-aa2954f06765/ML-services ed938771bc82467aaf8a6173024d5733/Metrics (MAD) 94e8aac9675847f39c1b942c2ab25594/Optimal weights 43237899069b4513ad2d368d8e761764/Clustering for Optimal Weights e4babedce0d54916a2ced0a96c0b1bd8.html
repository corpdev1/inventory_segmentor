Optimal Weights

For that, we use the F2-Score.

F2-measure puts more attention on minimizing false negatives than minimizing false positives.

The main problem with the F2-Score is that we need a ground truth to calculate Precision and Recall.

Cluster Optimisation

A fundamental step for any unsupervised algorithm is to determine the optimal number of clusters into which the data may be clustered. The Elbow Method is one of the most popular methods to determine this optimal value of k.

We iterate the values of k from 1 to 9 and calculate the inertia for each value of k in the given range.

Inertia is the sum of squared distances of samples to their closest cluster center.

To determine the optimal number of clusters, we have to select the value of k at the “elbow” ie the point after which the inertia start decreasing in a linear fashion.

In the case of we do a clustering we have 3 differents issues :

First: The perfect case

In this case, the clustering is useful and we could find the perfect k

Second : The worst

In this case, the clustering was a wast of time, and we decide to output no anomaly from the data

Third : The binary

In this case we have only two cluster, anomaly or not.
