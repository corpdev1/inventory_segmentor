Technical concepts

ARIMA

  • See here and here about the update equations of ARIMA models.
  • ARIMA (AutoRegressive Integrated Moving Average) models are linear regression based models where the regressors are past values (AutoRegressive) and residuals (Moving Average). Apart from these terms, the regression could be defined based on difference values computed using adjacent samples (Corresponds to Integrated in ARIMA).
  • ARIMA models have three parameters: p, d, q
    • p: Determines the previous samples in the regression equation (AutoRegressive part).
    • d: Order of the differencing. Used to remove trend.
    • q: Determines the previous residuals in the regression equation. Note: Don't confuse Moving Average with moving window average smoothing.
      • https://365datascience.com/tutorials/time-series-analysis-tutorials/moving-average-model/
      • A way to think about the moving average model is that it corrects future forecasts based on errors made on recent forecasts (from here).
  • SARIMA (Seasonal ARIMA) has four more parameters P, D, Q and m.
    • P, D and Q are similar to p, d and q but w.r.t. the seasonality.
    • m is the number of samples in a period (called "Frequency" parameter).
    • How does SARIMA handle seasonality?
      • Lags for Seasonal-AR (P), Seasonal-MA (Q) and Seasonal differencing (D) are multiples of the periodicity.
    • Note: SARIMAX is Seasonal ARIMA with eXogenous values.
  • What nonstationarity can be handled by ARIMA? In short, the presence of trend can be handled (linear, quadratic... polynomial, in general), if the trend is known before hand or can be estimated by the ARIMA model fitting algorithm. https://stats.stackexchange.com/questions/394796/should-my-time-series-be-stationary-to-use-arima-model

Observations and Conclusions

  • These techniques have fast prediction time because they are based on linear update equations.
  • Fitting ARIMA models is computationally heavy. It usually takes more time with increasing p, d, q, P, D, Q and m. However, it is not monotonic and the numerical optimization based fitting can converge faster unexpectedly for a particular set of parameters.
    • The Seagull paper from Microsoft also mentions that for ARIMA models fitting time is costly and prediction is efficient.
  • In our case the long computation times are because of the large value for the frequency parameter m.
    • See here for a discussion about this problem and possible work around using ARIMA and not SARIMA: The suggested work around is to model the seasonal part separately as a sum of Fourier terms and use only ARIMA for local prediction.
  • Spikes in the time-series are underestimated. Smoother changes are modeled better.
  • Setting the parameters is important to get good results.
    • More data will not help when these parameters are poorly set.
    • This article by Solarwinds about Holt-Winters says setting the right parameter values is important. It talks about searching over a large range of parameter values but their examples are based on the seasonal period parameter only. They mention very less about the other parameters. They claim to use MSE as the metric.
    • Searching over a large range of parameters, whether grid search (More than 12 hours. See here.) or by using auto-ARIMA, is taking a lot of time.
  • The auto-correlation function and the partial ACF are used to set the parameters p and q (respectively, P and Q). For e.g., see here. An initial guess based on such plots are important to search for the parameters.
    • A general rule of thumb is to set p to the lag that corresponds to the peak in the ACF. It is not yet clear what to do when the ACF peak happens at a very large lag value. Since, large p implies very long model fitting time.
    • See here for more notes.
  • The update equations of these models are such that when an anomaly happens, the prediction in the following time steps are affected.
  • Re-fitting the mode each time a new sample is seen is very time consuming. It is better to re-use a fitted model based on a filter approach, as described here for ARIMA.
    • The filter based approach for Holt-Winters is not appearing to be efficient. It needs to be investigated.
  • These ideas could be combined with other techniques like deep learning. e.g., look at the literature review section of n-beats paper.
  • SARIMAX performance is dependent on the solver. The optimization problem for fitting the model is non-convex and a local optimum is used. The output depends on how good a fit was obtained. See here and here for more details.
