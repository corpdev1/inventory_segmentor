Time-taken, Optimal error value etc

Observations

  • The script is based on fitting the Holt-Winters model again and again based on a sliding window of size 7 days, with a stride of 144 samples. The smoothing coefficients regarding level, trend and seasonal components are fixed based on the first window and are passed to the fit function in the subsequent windows.
  • We can see that the fitting takes a lot of time in the subsequent windows despite fixing these three values. According to the present understanding the only other parameter that needs to be estimated apart from the three smoothing coefficients is a parameter called damping_trend. It is not clear why the fitting routine takes a lot of time to estimate just one parameter in the later windows.
  • We can see that prediction of the 144 values at each step is quite efficient for all cases.
