First results of LSTM PoC for Sparse Data on MySQL

In this PoC we challenge different aggregation and also take theses different aggregation as a feature for the anomaly detection.

We also challenged the 3-Sigmas Rules against a Dynamic Threshold.

For the dynamic threshold, we will need two parameters — window inside which we will calculate threshold and std_coef. In our case, we take windows = 15 and std_coef = 3

Like Accumulator rule

The idea is to count the number of anomalies detected on a rolling windows of 30 min.

If we have less than x anomalies in this window we don't consider that we have anomaly.

Else, we have a local or global anomaly.

Create the rules

The rule is established on test data.

max_anomaly is the maximum anomaly observed on 30 min

global_anomaly threshold : 0.75* max_anomaly

local_anomaly threshold : 0.5* max_anomaly
