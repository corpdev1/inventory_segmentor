Concept shift

In the second experiment we will model a concept shift. The data is the following:

  • For the model without adaptation we miss anomaly due to sudden drop:
  • Adaptive models successfully catch this anomaly
  • There are no false positives in case of "peak anomalies" for adaptive models
  • It takes more time for adaptive model to accept new behaviour in case of the concept shift:

Conclusion

  • We can clearly see how the speed of adaptation of MAD model changes as we change the adaptation period (the longer the adaptation period the more it takes to adapt)
  • We observe higher anomaly scores for model with adaptation for new peaks (which are anomalous points)
  • The chance of missing the anomaly is decreasing while implementing adaptive models
  • It takes more time for MAD model to adapt to the concept shift
