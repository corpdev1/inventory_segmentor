Intro:

Clustering algorithm for set (unordered sequence of logs) anomaly detection.

Task:

Given a set of logs (unordered sequence), output wheather anomalous or not.

Main Idea: (Pretty intuitive)

Embed normal behaviour in the form of clusters (—> Very important to train the model on normal sets of logs !!). Outliers are data points that lie away from clusters.

How?

TF-IDF as feature extractor

Our aim is to project input to a vector space. We look at the problem from a standard NLP perspective, where inputs -which are sets of logs- can be seen as documents and templates as vocabulary.

Reminder: For a corpus of 'N' documents, a word 'w' in a document 'd'

Note:

Order information will get lost when we use TF-IDF to embed log sequences.

Eg:

"T1, T2, T3, T4, T5" and "T1, T3, T5, T2, T4" will have the same vector representation.

Clustering algo: Agglomerative Hierarchical Clustering (AHC)

Main idea:

Obtaining clusters as we move up in the hierarchy.

Hierarchy?

We start by having one cluster per data point. At each iteration, closest (—> Need a distance metric !!) pairs of clusters are merged. Once all clusters are too far apart, we stop clustering (—> Need a merging criterion !!).

One iteration = one move up the hierarchy.

Anomaly Detection

Once we have the clusters, we define a representative to each cluster in order to perform comparison with new data point (Anomaly detection —> Need to define an anomaly threshold)

Assigning Representative Log Sequence for each cluster:

After log clustering, we get a number of clusters. For each cluster, we select a representative log sequence by choosing the centroid of the cluster. To do so, we compute the score of each log sequence 'i' in a cluster based on its average distance to other log sequences in the same cluster:

where 'n' is the number of log sequences in the cluster. From each cluster, we select the log sequence with the minimal score as the representative sequence of the cluster. The selected sequences are the candidates for anomaly detection comparisons.

Anomaly Detection:

For a new data point (log sequence), we calculate its distance to every cluster representative and we get the minimum distance, if this distance is greater than an anomaly threshold, we flag an anomaly.

Conclusion

LogCluster two hyperparameters, θ\thetaθ﻿ or max_dist = maximum acceptable distance between clusters to merge. anomaly_threshold = maximum distance between a normal new observation and its closest cluster.

  • Higher max_dist means more merge operations which results in lower number of clusters at the end (and vice-versa)
  • Higher anomaly_threshold results in less reported anomalies (and vice-versa).
