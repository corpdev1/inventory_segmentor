let’s suppose that our data is x1, x2, ..., xt is the metric

3:04

The most used technique is the simple threshold as you already now this technique is called MASF (Multivariate Adaptive Statistical Filtering) :

  • compute the mean mu and sigma on some training data
  • if xt > mu + 3 sigma (99% of the data), declare anomaly
  • Advantages : very easy
  • Disadvantages : make the assumption that the data is coming from a normal distribution / many false alarms each sudden spikes

3:05

Point threshold (Turkey methods)

  • Compute Q1, Q3 for some training data
  • Declare serious anomaly when xt > Q3 + 3 x |Q3-Q1| or xt < Q1 - 3 x |Q3-Q1|
  • Advantages : no assumption about the data / very easy
  • Disadvantages : many false alarms each sudden spikes

Windowing approaches

  • Apply the above method to the mean of a window instead of a point
  • Advantages : no false alarms when sudden spikes
  • Disadvantages : fail to catch some anomalies

  • Heavy Never Occas Regul

4.5% 79.5% 8.5% 7.5%

  • The goal of the goodness of fit is to compare the observed distribution with the model (known distribution)
  • How : apply a chi2 statistics where the null hypothesis is “the observed data is consistent with the model”
  • The result is a p-value. If p-value is larger than a significance level, we can’t reject the null hypothesis and then both distribution are similar

And this is how Relative entropy technique works

  • Consider data coming from CPU usage. Since the data is between 0 and 1, we can discretize the data into, say, 10 buckets
  • Then we consider a window of size w, where we calculate the probability p of having data in ith bucket
  • The relative entropy compare a window of observed data with a prior model. For example, we can compare the current window distribution with the n previous distribution. If the distribution of the observed window is different from the prior window, we raise an anomaly
  • If the system behaviour changes, we raise an anomaly only at the change point, and then we compare with a newest window with the newest normal behaviour
