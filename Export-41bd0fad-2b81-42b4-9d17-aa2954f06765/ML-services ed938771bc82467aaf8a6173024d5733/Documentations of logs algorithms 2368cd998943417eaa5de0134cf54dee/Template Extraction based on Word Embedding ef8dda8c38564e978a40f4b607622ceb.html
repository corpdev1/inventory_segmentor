Once the logs are embedded, we can create some clusters.

Clustering step

  1. Create cluster
    • Compute the cosine similarity between the unique logs
    • Find the argmax of each unique logs
    • Define the argmax as a centroid
  1. Prediction step
    • Compute the cosine similarity between the logs and the centroids
    • Find the max cos sim
    • Find the argmax of each row logs
    • Output the cluster and the maximum value

  1. Update the clustering
    • If the max cos sim<0.975 we update the clustering by adding new centroid
    • We repeat the 2nd only on logs where cos sim is under 0.975
