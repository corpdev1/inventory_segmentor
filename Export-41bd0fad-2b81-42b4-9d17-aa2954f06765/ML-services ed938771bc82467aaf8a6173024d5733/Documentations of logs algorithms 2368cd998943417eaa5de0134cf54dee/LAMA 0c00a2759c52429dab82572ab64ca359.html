Detecting Log Anomalies with Multi-Head Attention (LAMA)

Introduction

Why use Multi-Head attention :

  • Statistical models ignore sequence orders
  • RNN based models fail to explicitly capture fine grained relationships between events in long sequences.

Multi-Head attention mechanism proved to be powerful in capturing sequence features in NLP tasks with a lightweight architecture.

Methodology

The paper supposes that the logs were already parsed to templates (Drain).

For a set of events E1,E2,…,EnE1, E2, \dots, EnE1,E2,…,En﻿, run a sliding window of length lll﻿ to predict the next event.

Once model is trained, the algorithm will make inference this way :

  • Run a sliding window over a set of logs Session=[E1,E2,E3,E4,E5,E6]Session = [E1, E2, E3, E4, E5, E6]Session=[E1,E2,E3,E4,E5,E6]﻿
  • Predict the next event for all the windows
  • If the predicted next event is not in the TopkTopkTopk﻿ candidates predicted by the model, the window is labelled as abnormal
  • If one window is labelled as abnormal, the whole sequence of logs is labelled as abnormal

Architecture

The architecture employed in this paper is inspired from Attention is all you need https://arxiv.org/abs/1706.03762 that introduced Multi-Head attention.

:The LAMA architecture, figure below, uses 4 main layers :

  • Embedding : It maps each input vector to a fixed size vector of dimension ddd﻿
  • Position Encoding : It encodes the position of the events based on a sine and a cosine functions as suggested by the paper. The output is then summed to the embedding vector
  • Attention : It's a mix of Multi-Head attention layer and feed forward network. Residual and layer normalisation blocks are applied. The dimension of the feed forward network and the number of heads hhh﻿ needs to be specified
  • Linear : It maps the output of the attention layer to a vector of size the number of templates in order to classify the sequences

Performance

To evaluate the model, the authors used the HDFS logs dataset that contains about 11.7M logs.

The dataset is labelled by session (set of logs).

The authors did two main experiments :

  • Split the normal data to 80/20, use 80% for training and the abnormal data+20% of normal data for testing
  • Split the normal data to 1/99, use 1% for training and the abnormal data+99% of normal data for testing

Conclusion

The performance obtained by LAMA is very promising. The architecture is also lightweight and needs by far less ressources and time to train compared to RNN based model. This architecture consider also the order of the events in a sequence.
