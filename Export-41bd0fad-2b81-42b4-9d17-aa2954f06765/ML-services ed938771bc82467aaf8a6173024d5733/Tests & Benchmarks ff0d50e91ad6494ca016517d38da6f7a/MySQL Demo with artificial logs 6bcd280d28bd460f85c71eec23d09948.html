Introduction

Objective : Prepare the demo to show anomalies on MySQL technology

How :

  • Create a script to generate artificial anomalie on MySQL error logs
  • Ship the data through the main pipeline :
    • Install filebeat and configure to harvest data from MySQL module to kafka topic
    • Ensure data is transformed through logstash and pushed back to kafka
  • Train LAD over the normal generated
  • Show the anomaly and the corresponded logs on kibana while generating abnormal data

Data shipment

Below is the used configuration of filebeat in order to ship data from MySQL error logs to kafka

filebeat.modules:
- module: system
  syslog:
    enabled: false
- module: mysql
  error:
    enabled: true


output.kafka:
  enabled: true
  hosts: ['broker3.packetai.co:19091', 'broker3.packetai.co:29091', 'broker3.packetai.co:39091']
  topic: 'de2-de2-log-mysqldemologs-raw'

Data Generation

The generated logs are created through Jinja2 Template :

Normal templates

[
    {
        "template": Template('Database {{ db_name }} migrated to server {{server_name}}'),
        "fields": {"db_name": str, "server_name": str}
    },
    {
        "template": Template('Database {{ db_name }} has {{n_rows}} row'),
        "fields": {"db_name": str, "n_rows": int}
    },
    {
        "template": Template('Server {{ server_name }} stopped'),
        "fields": {"server_name": str}
    },
    {
        "template": Template('Server {{ server_name }} started with status {{status}}'),
        "fields": {"server_name": str, "status": int}
    },
]

Abnormal templates 

[
    {
        "template": Template('Error {{ error_number }} while connecting to host {{host_name}}'),
        "fields": {"error_number": int, "host_name": str}
    },

]

Below the functions used to generated the final logs

def generate_random_string():
    letters = string.ascii_lowercase
    random_string = ''.join(random.choice(letters) for _ in range(5))
    return random_string


def generate_fields(field_dict):
    fields = {}
    for k, v in field_dict.items():
        if v == str:
            fields[k] = generate_random_string()
        elif v == int:
            fields[k] = random.randint(0, 10)
    return fields
