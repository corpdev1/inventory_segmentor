  • Normalized streaming score (score divided by maximum score in the matrix profile).
  • Raw matrix profile score.

Possible ways to analyse the score:

  • Sum of the scores.
  • Variance of the time stamps at which anomaly is detected. Anomaly detected with a threshold of 0.8.
