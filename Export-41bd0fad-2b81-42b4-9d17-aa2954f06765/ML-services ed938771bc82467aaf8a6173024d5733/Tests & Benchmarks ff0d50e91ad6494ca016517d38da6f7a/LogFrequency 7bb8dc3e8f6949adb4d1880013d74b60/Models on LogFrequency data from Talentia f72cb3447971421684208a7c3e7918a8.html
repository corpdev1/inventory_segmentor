Models on LogFrequency data from Talentia

This page aims to make a comparison between time-series anomaly detection models applied on LogFrequency

As a benchmark, we took the logfrequency data from Talentia that was aggregated by 30minutes :

We then run a moving average algorithm on the same data since we noticed the importance of the smoothness of the data

HOT-SAX

  • Method :
    • Divide the series into alphabet sequences with PAA method
    • Find anomalous sequences in data
  • Link : https://github.com/seninp/saxpy

  • It detects abnormal sequences
  • It does not detect abnormal jumps

Random Forrest Regressor

The goal was to model the time-series with a regression. We extracted the feature from the timestamp (is_weekend, hour) and split the time-series to train and test.

  • Prediction is poor since we lack data and features
  • Could be applied when we get more data

ADTK Threshold

Declare anomaly when the data value is above some threshold.

  • Easy to use
  • Need to fix a threshold which has to be known a priori
  • Doesn't catch any other form of anomalies

ADTK Quantile

Instead of fixing the threshold, we can fix the quantile

This works better on moving averaged data

FB Prophet

FB prophet is a package to model seasonal time-series data

  • Link : https://facebook.github.io/prophet/

  • Works better on moving averaged data
  • Needs more data to converge
