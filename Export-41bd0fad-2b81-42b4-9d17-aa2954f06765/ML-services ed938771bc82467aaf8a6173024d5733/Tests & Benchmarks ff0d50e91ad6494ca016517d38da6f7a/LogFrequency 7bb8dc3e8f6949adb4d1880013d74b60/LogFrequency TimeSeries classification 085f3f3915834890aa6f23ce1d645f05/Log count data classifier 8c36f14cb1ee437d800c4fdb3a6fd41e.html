Classification based on custom features

Feature description

Let us introduce the following features:

"mean"
"std"
"unique_vals_count" (unique values count)
"median"
"more_than_quantile95" (count of values that are greater than the 95th quantile)
"fraction_of_zeros"
"fraction_of_nonzeros"
"cumsum_perc_top_1" (cumulative percentage of the 1st value of sorted counter)
"cumsum_perc_top_2"
"cumsum_perc_top_3"
"cumsum_perc_top_4"
"cumsum_perc_top_5"
"total_values" (total number of values)
"total_zeros" (total number of values that are equal to zero)
"total_nonzeros" (total number of values that are not equal to zero)
"nonzero_mean" (avg of non-zero values)
"nonzero_std" (std of non-zero values)

We were extracting the features above from the initial dataset, diff dataset (dataset of value differences df.diff()). Also we were splitting initial dataset and the diff dataset into a set of non-intersecting buckets, extracting these features from each of the bucket and calculating an average and the std of each of these features along the buckets.

Finally, our training dataset was assembled from the following data:

[
general_features, # features extracted from initial dataset
mean_bucket, # avg of features extracted from initial dataset splitted into 20 buckets
std_bucket, # std of features extracted from initial dataset splitted into 20 buckets
mean_bucket_diff, # avg of features extracted from diff dataset splitted into 20 buckets
std_bucket_diff, # std of features extracted from diff dataset splitted into 20 buckets
diff_general_features, # features extracted from diff dataset
]

Preprocessing functions description

Before the feature generation we were applying the following two functions: remove_outliers and remove_drift

remove_outliers: removes outliers based on the z-score

remove_drift: detects change points and removes the drift by subtracting the difference between the average of data before and after detected change point
