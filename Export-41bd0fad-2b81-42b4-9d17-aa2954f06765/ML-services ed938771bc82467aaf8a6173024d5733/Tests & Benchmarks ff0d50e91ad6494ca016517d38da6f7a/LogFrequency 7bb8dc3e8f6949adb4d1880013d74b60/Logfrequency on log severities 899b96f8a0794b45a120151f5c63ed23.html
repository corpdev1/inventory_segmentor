Introduction

The goal of this report is to investigate the applicability of Logfrequency anomaly detection on the count of the log severities.

Log severities, also known as log levels, belong generally to these categories :

  1. CRITICAL
  1. ERROR
  1. WARN
  1. INFO
  1. DEBUG

In practice, the total number of logs could hide some information since it aggregates all the logs together independently from their severities. However, N messages with ERROR level is more informative about potential issue rather than N messages with INFO message.

Conclusions

  • Most of the time series that are error or warning have no clear pattern
  • It is non expected to have an error distribution that has a clear pattern. Because it means that errors are happening all the time and need to be fixed.
  • Our current set of Logfrequency detectors doesn't support sparse data with no patterns shapes, for this, we need to develop a new and simple model for this kind of time series.
