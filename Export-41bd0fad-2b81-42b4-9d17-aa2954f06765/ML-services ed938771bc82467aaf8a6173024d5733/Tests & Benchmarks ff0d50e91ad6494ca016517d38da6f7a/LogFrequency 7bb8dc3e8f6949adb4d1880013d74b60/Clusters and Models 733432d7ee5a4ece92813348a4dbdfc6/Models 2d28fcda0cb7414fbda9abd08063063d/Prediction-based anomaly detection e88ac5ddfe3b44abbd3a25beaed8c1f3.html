Prediction-based anomaly detection

Advantages- Could be evaluated while fine tuning it
Data with driftDense data around the mean value, Random noisy data
Data without driftDense data around the mean value, Random noisy data
Disadvantages- Slow - Need some tweaking

Supervised learning is about learning a model to predict the next point. And if the predicted value is far from the real value, the it's an anomaly.

For this tests, the KNNRegressor from River package was used with :

  • window_size: 1 day
  • aggregation_method: median

Also, the data was processed by an online MinMaxScaler from River.

Finally, some features were added to the model :

  • current hour
  • current weekday
  • current minute
  • the shifted value of the target by -1
  • the shifted value of the target by -2
  • the shifted value of the target by -3
  • the shifted value of the target by -4
  • the shifted value of the target by -5

After comparing the prediction with the actual value, a threshold need to be set in order to decide if it's an anomaly.
