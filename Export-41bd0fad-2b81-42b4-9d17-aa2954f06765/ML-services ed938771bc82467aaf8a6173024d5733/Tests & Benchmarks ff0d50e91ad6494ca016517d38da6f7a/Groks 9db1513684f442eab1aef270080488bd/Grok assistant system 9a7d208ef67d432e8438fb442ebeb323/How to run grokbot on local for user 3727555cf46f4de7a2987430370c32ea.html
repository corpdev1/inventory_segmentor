How to run grokbot on local for user

Requirements

  • gcloud
  • k8s
  • python (link for PyCharm)

Connect to staging env in a terminal

If you use ec2:

ssh -NL 9200:localhost:9200 -i aws_paris_instance.pem ubuntu@ip
ssh -NL 5601:localhost:5601 -i aws_paris_instance.pem ubuntu@ip

If you use staging env:

If gcloud is not installed :

Download Google cloud SDK

Install here: https://cloud.google.com/sdk/docs/install

  • Install here: https://cloud.google.com/sdk/docs/install
  • Run gcloud init
  • Enter project as packetai

Follow this link to install k8s

import k8s cluster: Run below

gcloud container clusters get-credentials gke-stage-prod --region europe-west3 --project packetai

If you have this error, ask Rama to give you access to the cluster

Fetching cluster endpoint and auth data.
ERROR: (gcloud.container.clusters.get-credentials) ResponseError: code=403, message=Required "container.clusters.get" permission(s) for "projects/packetai/locations/europe-west3/clusters/gke-stage-prod".

kubectl get pods -n od-system to get $es_client_pod name

kubectl port-forward $es_client_pod 9200:9200 -n od-system
