Logstash Filter Verifier

Installation

export LFV_VERSION=1.6.3
curl -LJ https://github.com/magnusbaeck/logstash-filter-verifier/releases/download/${LFV_VERSION}/logstash-filter-verifier_${LFV_VERSION}_linux_amd64.tar.gz -o lfv.tar.gz
# For Mac Uses: curl -LJ https://github.com/magnusbaeck/logstash-filter-verifier/releases/download/${LFV_VERSION}/logstash-filter-verifier_${LFV_VERSION}_darwin_amd64.tar.gz -o lfv.tar.gz
mkdir lfv
tar -vxf lfv.tar.gz -C lfv
cd lfv
./logstash-filter-verifier test.json test.conf

Logstash configuration file

filter {
  grok {
    match => { "message" => "\[%{TIMESTAMP_ISO8601:logdatetime}: %{WORD:loglevel}/%{DATA:process}\] %{GREEDYDATA:content}" }
  }
}

Explain

  • codec

    Work the same as codec in the logstash configuration

  • input, output

    LFV will automatically remove the input and output field in the logstash configuration so no need to have a seperate file for the configuration.

  • ignore

    host and @timestamp are usually ignored because they contains local information. host is the machine that are running logstash which is an instace for testing.

  • input, expected

    A list of log messages ( string ) and the expected parsing output ( dictionary ). Note that JSON should be feeded to input as an escaped string, e.g "{\"message\": \"This is a test message\", \"client\": \"127.0.0.1\", \"time\": \"2015-10-06T20:55:29Z\"}".

Troubleshoot

Error locating Logstash: no existing executable found among candidates

  • Use --logstash-path
  • sudo ln -s $(which logstash) /usr/share/logstash/bin/
  • sudo ln -s $(which logstash) /opt/logstash/bin/

Couldn't find the wanted files (jvm.options, log4j2.properties) in any of these directories: /opt/logstash/config, /etc/logstash

  • sudo ln -s /usr/local/etc/logstash/ /etc/
  • sudo ln -s /usr/local/etc/logstash/ /opt/logstash/config
