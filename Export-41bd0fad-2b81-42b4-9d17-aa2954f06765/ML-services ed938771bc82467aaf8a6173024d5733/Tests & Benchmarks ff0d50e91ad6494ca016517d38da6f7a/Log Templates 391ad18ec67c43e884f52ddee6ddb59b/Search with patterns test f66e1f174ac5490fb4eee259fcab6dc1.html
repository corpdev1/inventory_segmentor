In order to find these patterns in elasticsearch, we use this query 

GET index-6040a96cdcc614001153fc55-docker-log-rabbitmqqueue_rabbitmq/_search
{
  "query": {
    "bool": {
      "must": [
        {
          "query_string": {
            "query": elk_pattern,
            "default_field": "message"
          }
        },
        {
          "range": {
            "@timestamp": {
              "gte": "1632639600000",
              "lte": "1632643200000"
            }
          }
        }
      ]
    }
  }
  
}

where elk_pattern is a transformation of the pattern found by drain :

  • split the pattern based on whitespace
  • add ( and ) at the beginning and the end of each token respectively
  • escape these letters + - = && || > < ! ( ) { } ^ " ~ * ? : \ / \' if any by adding \\ in front of each character

example : accepting AMQP connection < <*> > ( <*> - > <*> ) → (accepting) AND (AMQP) AND (connection) AND (\\<) AND (\\>) AND (\\() AND (\\-) AND (\\>) AND (\\))
