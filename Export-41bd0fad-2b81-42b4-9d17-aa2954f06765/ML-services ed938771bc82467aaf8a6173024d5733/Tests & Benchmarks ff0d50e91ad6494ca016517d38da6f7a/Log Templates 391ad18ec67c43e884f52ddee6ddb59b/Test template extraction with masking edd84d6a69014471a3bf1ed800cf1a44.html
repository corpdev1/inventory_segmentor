Introduction

The goal of this test is evaluation the masking function, used as preprocessing for template extraction, over many topic examples.

Test methodology

  • Downloaded 53 topics from Affluences and Zerogachis that are already parsed using logstash. The tests could be improved after more groks for the rest of the topics
  • Run the template extraction algo over the contents using Drain without masking function
  • Run the template extraction algo over the contents using Drain with masking function

Conclusion

  • The masking is providing with cleaner templates
  • The masking is helping to group same templates together
  • Some masking functions could lead to a dangerous overgeneralisation
  • Some masking functions are hiding the true meaning of logs
  • The tests shall improve after providing with more groks and being able to test on more contents
  • The results shall improve if we provide with better masking instructions
