LogCluster performance test

We built two anomaly detection pipelines one with different template extraction algorithms (Logan and Drain+Mike+Gale) and with LogCluster as the AD algo.

As a dataset, we used HDFS.

Here are the details/results of the test.

Model parameters:

Template extraction :

Logan : alpha=1, beta=2 Drain : similarity threshold=0.5, depth=4

Anomaly detection : LogCluster

max_distance=0.3 anomaly_threshold=0.3

Results:

We took 200k logline of HDFS, aggregated them according to their block ids and then split them in half train/test. The test data contains 225 actual anomalies.

Interpretation:

  • Good precision: Indicates very low rate a false positives (false alarms). When we detect an anomlay, where are pretty much confident that it is actually a real anomaly.
  • Bad recall: Indicates high rate of false negatives (misses). LogCluster fails to detect all the anomalies.
