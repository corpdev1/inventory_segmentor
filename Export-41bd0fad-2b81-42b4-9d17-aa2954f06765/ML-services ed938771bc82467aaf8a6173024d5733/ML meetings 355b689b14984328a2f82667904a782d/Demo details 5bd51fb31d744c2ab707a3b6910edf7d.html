Script description

Script 1 (Concept Shift)

  • Normal state: 1 thread is running
  • Abnormal state: 5 threads are running
  • Thread actions:
    • Each iteration we randomly choose one of the following operations to perform:
      1. Insert random number of rows into the table (from 1 to 200 rows)
      1. Delete random number of rows from the table (from 10 to 100 rows)
      1. Modify random number of rows in the table (from 5 to 50 rows)
      1. Gentle sort (choose a random subset of table rows and sort that rows by values from one of the columns)
      1. Big sort (sort all rows from the table by values from one of the columns)
    • If the total number of rows in the table is more than 6000 we delete 4000 rows from the table
    • If the total number of rows in the table is less than 10 we insert random number of rows into the table (from 100 to 300 rows)
    • The sleep time between each iteration is equal to 0.5 seconds + some random amount of seconds (from 0 to 0.05)
  • Test 1: 1 hour of normal state → 30 minutes of abnormal state → 1 hour of normal state

Script 2 (Cluster)

  • Normal state: each 10 seconds we insert 5 rows into the table, delete 5 rows from the table and modify 5 rows in the table
  • Abnormal state: each 2.5 seconds we insert 50 rows into the table, delete 15 rows from the table and modify 500 rows in the table
  • Test 1: 30 minutes of normal state → 10 minutes of abnormal state
  • Test 2: 30 minutes of normal state → 10 minutes of abnormal state → 10 minutes of normal state and interrupt the script which should cause an error log (outlier anomaly)

Script 3 (Cluster + Frequency)

  • Normal state: each 10 seconds we insert 5 rows into the table, delete 5 rows from the table and modify 5 rows in the table
  • Abnormal state (log cluster anomaly): each 60 seconds we insert 150 rows into the table
  • Heavy load state (log frequency anomaly): each 10 seconds we insert 1250 rows into the table, delete 1250 rows from the table and modify 1000 rows in the table
  • Interruption: we kill the process (with script) which causes an error log
  • Test 1: 30 minutes of normal state → 10 minutes of abnormal state → 30 minutes of normal state → 10 minutes of heavy load state. We interrupt the script after 75 seconds
