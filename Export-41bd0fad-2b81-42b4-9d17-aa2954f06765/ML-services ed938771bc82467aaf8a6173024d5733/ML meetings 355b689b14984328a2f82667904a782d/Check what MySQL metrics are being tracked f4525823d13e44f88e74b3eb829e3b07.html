Metricbeat Setup

  1. Install Elasticsearch 
brew tap elastic/tap
brew install elastic/tap/elasticsearch-full

2. Install Kibana

brew tap elastic/tap
brew install elastic/tap/kibana-full

3. Install Metricbeat

curl -L -O https://artifacts.elastic.co/downloads/beats/metricbeat/metricbeat-7.9.2-darwin-x86_64.tar.gz
tar xzvf metricbeat-7.9.2-darwin-x86_64.tar.gz

4. Run Elasticsearch :

elasticsearch

4. Run Kibana

kibana

5. Run Metricbeat with default pipeline

cd metricbeat-7.9.2-darwin-x86_64
./metricbeat -e

6. Run Metricbeat with a specific pipeline : ./metricbeat -e -c specific_pipeline.yml

To see the outputs of metricbeat :

  1. Go to http://localhost:5601/ to open up kibana dashboard
  1. Check the Discover under Kiabana on the right side menu
  1. Change the index pattern to : metricbeat-*

To know the list of modules: ./metricbeat modules list

To activate a module :

  1. CLI : ./metricbeat modules enable apache mysql
  1. Or change the pipeline : 
    metricbeat.modules:

#---------------------------- Apache Status Module ---------------------------
- module: apache
  metricsets: ["status"]
  period: 1s
  hosts: ["http://127.0.0.1/"]

#---------------------------- MySQL Status Module ----------------------------
- module: mysql
  metricsets: ["status"]
  period: 2s
  hosts: ["root@tcp(127.0.0.1:3306)/"]

To change the index name for ealsticsearch :

  1. Change the pipeline.yml file
output.elasticsearch:
  hosts: ["http://localhost:9200"]
  index: "specific-index-name"

2. Create a new index pattern on Kibana :

  • Click on Create New Index Pattern under http://localhost:5601/app/management/kibana/indexPatterns
  • Specify the index pattern : specific-index-name-* for example
  • Make sure to select the specific-index-name-* on Discover
