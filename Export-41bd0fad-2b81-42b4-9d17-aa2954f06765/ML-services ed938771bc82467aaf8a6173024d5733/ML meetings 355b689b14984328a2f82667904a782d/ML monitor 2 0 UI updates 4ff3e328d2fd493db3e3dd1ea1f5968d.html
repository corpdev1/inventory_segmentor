New ml_monitor v2 API @dengke li

  • The API of ml_monitor v2 should send data by component not by topic/index(logs and metrics separated)
  • It will contain two separate endpoints
    • an endpoint that returns a list of the data statues for each component for a given infrastructureId(used by the admin page)
    • an endpoint that returns logs freshness(used by the logs page)
