Description:

How I evaluate the TE with an Embedding

The objective is to find the log templates

Once the Embedding matrix is fit, we send our log templates and our logs in our embedding space.

How to send our logs in our embedding space

For each word in the template, we get it embedding vector

Then we aggregate by taking the sum or the mean for each embedding axis

Associate a log to a Template

So after the aggregation step, we've got one vector for each log and for each log template.

So we compute the Cosinus similarity between logs and template.

Then to associate a log to a template we take the max value on a row.

def preprocess(sentence):
	""" INPUT : Sentence
	OUTPUT : Sentence
	Pre processing step for text """
	sentence=str(sentence)
	sentence = sentence.lower()
	sentence=sentence.replace('{html}',"")
	cleanr = re.compile('<.*?>')
	cleantext = re.sub(cleanr, '', sentence)
	rem_url=re.sub(r'http\S+', '',cleantext)
	rem_num = re.sub('[0-9]+', '', rem_url)
	tokenizer = RegexpTokenizer(r'\w+')
	tokens = tokenizer.tokenize(rem_num)
	return " ".join(tokens)
