This roadmap is extremely opportunistic and pragmatic (hence very volatile). Every project included is evaluated based on 3 aspects:

  • Worthiness: is there a value for clients
  • Feasibility: is it technically feasible in an acceptable time span
  • Priority (function of the 2 previous): is this the immediate focus? could it wait ?

Release July 2021

includes following features:

  • automatic detection of anomalies

    metrics

    • detect individual anomalies on metrics including: infra metrics, containers, apps ...
    • correlate anomalies into "issues". An issue is a set of anomalies that belong to the same abnormal situation. This reduces the alerting noise

    logs

    • outlier log detection (rareness)
    • sentiment analysis (negativity)
    • log frequency anomaly
    • log pattern anomaly
    • log sequence anomaly
    • correlate anomalies that belong to the same "issue" for noise reduction
    • a log anomaly dashboard that contains explanations of the anomalies

  • a unified anomalies page that makes it easy to correlate anomalies across metrics and logs
  • user feedback on metrics and logs

    the user can give detailed feedback on the output of all anomaly detection algorithms

  • automated RCA
    • a visual explanation of the Root Cause, propagation and symptom of an issue (the issues page)
    • ability to give feedback on the automated RCA results

Additional Pitch elements

  • Works in real-time, on the cloud using large scale data from any software, either through an API or a small relay.
  • Monitors any time series metrics and identifies deviations (anomalies) from your metrics’ normal behavior patterns, as learned through PacketAI's algorithms.
  • Metrics option enables you to easily create and configure metrics.
  • The Issues page enables you to isolate specific components or metrics that might be causing your IT infra problems. In the Anomalies page you can view the anomalies that PacketAI has identified, drilldown to understand the time framework of the anomaly, zoom in to specific elements of the anomaly, apply filters to manipulate the display to gain greater insights to the severity and causes of the anomaly, and also give feedback.
  • Configurable alerts interface can notify you when metrics have crossed automatically-identified normal or customized thresholds.

Release September 2021

  • enhanced detection ability of our internal algorithms: result of using user feedback and algorithmic improvements
  • support for user-controlled detection sensitivity: the user can lower or higher the sensitivity of the anomaly detection engine from the UI
  • support for general auto-alerts per KPI type: Example, apply some parameters on all CPU KPIs on all containers of Nginx.
  • support for planned downtime (including recurrent holidays for eg ..):

    the user can specify dates when the system is supposed to be down so our algorithms do not consider those as incidents

  • advanced anomaly dashboards with better visualisations and better interactivity. For eg, the user can select an abnormal area on the chart and give feedback on it
