Log pattern variable representation and solution

This mail is intended to make everyone knows what's the incoming and upcoming big picture and to help people if they experience some difficulties.

Motif

In order to let user understand more on the log, apart from offer log pattern to log UI, packetai can also show the variables of log pattern in the position of wildcard. Since each log pattern can have multiple variables due to many logs of this pattern, we have to give some smart representation

of those variables for each pattern.

Log pattern variable representation

proposition1:

  1. for numeric value: we use range like [min, max]
  1. for string value: we show N most occurrent string, ex: N=5
    1. Possibility to just count unique values → description=”<788 uniques> some_text here bla bla bla” → Bloom filter
    1. Possibility to just count unique values → description=”<100+ uniques> some_text here bla bla bla”

Design solution

proposition1:

we send every variable to ES with template_id , then frontend query those variables for same template_id, and get the range

pros: flexisible to ajust or change the representation algorithm

cons: may have frontend performance impact

proposition2:

in logpattern service, each time we extract variables, we check with the existing range in mongo and update the range to mongo lad_templates  , then frontend get the range directly from mongo

pros: frontend can direclty get the calculated value without algorithm calculation

cons: it may impact logpattern service performance

proposition3:

in logpattern service, each time we extract variables, we send to kafka, another service calculate the range and update to mongo

pros: frontend can direclty get the calculated value without algorithm calculation, also don’t impact logpattern service, new service total decoupled from logpattern service

cons: additional service

Decision: choose proposition3

plus feature: to support masking wildcard variables

expose api to put range/count into template for frontend

Implementation and features
