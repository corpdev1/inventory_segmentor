Another way to analyse is to look at the anomalies that are the inputs to the DBScan algorithm. One such set of anomalies is in the following file:

These anomalies are the set of all anomalies detected by MAD before noise suppression (i.e., all cases where anomaly score > threshold).

In this particular file, there are 72589 anomalies.

We then use agglomerative clustering of anomalies with a threshold of 3600 seconds, to create abnormal regions. Then the total number of resulting abnormal regions = 39423

To more easily analyse the 39423 regions, the number of anomalies in each of the abnormal regions was considered.
