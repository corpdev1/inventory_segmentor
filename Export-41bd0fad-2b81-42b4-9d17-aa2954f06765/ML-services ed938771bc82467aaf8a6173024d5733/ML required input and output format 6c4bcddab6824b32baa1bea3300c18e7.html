Intro

The required input and output format are listed below. All fields are required except those underlined ones.

Variable field names are coloured in yellow.

MAD

Input format

The incoming message should have the following mandatory fields:

{
		"timeI": int # timestamp in seconds
		"timeS": str  # human timestamp of the format "%YYYY-%mm-%ddT%HH:%MM:%SS"
		"infraID": str # infrastructure ID
		"agentID": str # agent ID
		"componentID": str # component ID
		"techno": str # technology type name
		"metrics": list # list of metrics 
}

The list of metrics should be of the following format:

[
		{
				"subject": str, # subject name (could be an empty string)
				"metric": str, # metric name
				"value": float, # metric value
				"dataset": str, # metric dataset
				"time": str, # datetime of the format "YYYY-mm-ddTHH:MM:SS.msZ"
		},
		...
]

Output format

{
		"timestamp": int, # timestamp in milliseconds
    "isAnomaly": bool, # True if any of the metrics was detected as anomaly
		"@timestamp": str, # timestamp in str format "%Y-%m-%dT%H:%M:%S.%fZ"
		"detector": "mad",
		metric_name1: {
                "isAnomaly": bool, # prediction, True if detected as anomaly
                "value": float, # metric value
                "anomalyScore": float, # metrics anomaly score (value between 0 and 1)
                "threshold": float # MAD anomaly threshold (value between 0 and 1)
                "absolute_delta": float, # absolute delta (equals to -1 in case no abslolute delta is provided))
            }
		metric_name2: {...},
		...
		"warmup": bool, # True if MAD is in warmup period
		
		
		"ml_data": {
		        "warmup": {
												"general": bool, # True if #{points processed by MAD} > warmup_period
												"metric_name": bool, # if we have collected enough data for this metric 
											},
						"duration_deviation": dict, # this dictionary contains SIRE input. See the required format below
		        "noise_reduction": {
																		"metric_name": {
																                        "dbscan_importance": bool, # True if anomaly is significant according to dbscan importance algorithm
																                        "sire_p_importance": bool, # True if anomaly is significant according to sire-p importance algorithm
																                    },
																},
		        "sire_p": {
												"metric_name": float, # sire-p relevance score per metric
											},
		        "detector_outputs": dict, # contains individual scores of each MAD detector
		    }
}
  • More details about the absolute delta could be found here
  • metric_name is formed based on metric (metric) and subject (subject) names as follows: metric-subject
  • duration_deviation dictionary should be of the following format:
{
    "deviation": float, # abnormal period's deviation
    "duration": int, # abnormal period's duration in seconds
    "start": int, # abnormal period's start timestamp in milliseconds
    "end": int, # abnormal period's end timestamp in milliseconds
}
  • detector_outputs dictionary should be of the following format:
"detector_outputs": {
		detector_name: [anomaly_score_for_metric_1, anomaly_score_for_metric_2, ...],
		...
}

Output format

MLLOG : infraID-agentID-mllog-componentID

{
		"timestamp": int, # timestamp in milliseconds
		"datetime": str, # datetime of the format "%Y/%m/%d, %H:%M:%S",
		"@timestamp": str, # timestamp in str format "%Y-%m-%dT%H:%M:%S.%fZ"
		"detector": "lad",
		"isAnomaly": bool, # True if any of output['negativeLogs']["isAnomaly"] or output['logFrequency']["isAnomaly"] is True
		"value": int, # log count
		"logFrequency": {
		    "value": int # number of messages,
		    "isAnomaly" : bool # any(levels[isAnomaly])
		    "anomalyScore" : float # max(levels[anomalyScore])
		    "levels" : [
		        {
		           "filter": "general", # log filter related to all incoming logs
		           "value": int, # log count
		           "isAnomaly" : bool, # True or False
		           "anomalyScore" : float, # anomaly score (value between 0 and 1)
		           "models" : { # info about deployed models
										logFrequency_detector: {
													"isAnomaly": bool, # True or False 
													"anomalyScore": float, # anomaly score (value between 0 and 1) 
													}
										}
		        },
		        {
		           "filter": "warning", 
		           "value": int, # log count
		           "isAnomaly" : bool, # True or False
		           "anomalyScore" : float, # anomaly score (value between 0 and 1)
		           "models" : { # info about deployed models
										logFrequency_detector: {
													"isAnomaly": bool, # True or False 
													"anomalyScore": float, # anomaly score (value between 0 and 1) 
													}
										}
		        },
		        {
		           "filter": "error",

		           "isAnomaly" : bool, # True or False

													"isAnomaly": bool, # True or False

													}
