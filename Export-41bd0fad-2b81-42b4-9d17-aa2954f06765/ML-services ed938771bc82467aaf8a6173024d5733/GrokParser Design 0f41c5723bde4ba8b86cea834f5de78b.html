GrokParser Design

Discussion notes

  1. GrokBot
    1. User create groks for topic
    1. Grokbot save Groks into Database, and create a new session_id at backend - https://packetai.atlassian.net/browse/BEP-2738
  1. UI. - https://packetai.atlassian.net/browse/BEP-2741
    1. UI show to user the list of Groks submitted with status=Grokbot -
    1. If user click Update, it will send a request to Backend in order to start a workflow, backend will increase iteration_id for the session_id and save these two info in backend
    1. UI will poll information from DB until it get new data with status=Grokparser and complete_state
    1. When workflow finishes, UI will show the Templates | Contents | Logs | Groks to the user
    1. User can Edit/Rearrange Groks, then click Update button → step b.
    1. User can validate Groks by clicking Validate button
  1. Backend
    1. When Backend is triggered, it will extract contents, extract templates and apply KPI score, and increase iteration_id
    1. Then it save result in DB with status=Grokparser and version=V
    1. And save Templates | Contents | Logs | Groks to S3
