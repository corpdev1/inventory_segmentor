Deploying a model with kfserving

We assume a cluster is up.

IMPORTANT! Workaround for kfnative gateway issue

  1. Configure knative config-istio configmap in knative-serving namespace to use the kubeflow gateway
    1. run -> kubectl edit cm config-istio -n knative-serving
    1. replace gateway.knative-serving.knative-ingress-gateway: kfserving-ingressgateway.istio-system.svc.cluster.local withgateway.kubeflow.kubeflow-gateway: istio-ingressgateway.istio-system.svc.cluster.local
  1. Configure kfserving inferenceservice-config configmap to use the kubeflow gateway
    1. run →kubectl edit cm inferenceservice-config -n kubeflow
    1. replace 
    "ingressGateway" : "knative-ingress-gateway.knative-serving",
"ingressService" : "kfserving-ingressgateway.istio-system.svc.cluster.local"

    with 

    "ingressGateway" : "kubeflow-gateway.kubeflow",
"ingressService" : "istio-ingressgateway.istio-system.svc.cluster.local"

IMPORTANT! Workaround for registries tag resolving

  1. run - > kubectl -n knative-serving edit configmap config-deployment
  1. add your local registry to registriesSkippingTagResolving

Create a namespace kfs

kubectl create namespace kfs
kubectl label namespace/kfs serving.kubeflow.org/inferenceservice=enabled

Deploy a model (kfserving-custom-model in kfserving samples)

cd kfserving/docs/samples/custom/kfserving-custom-model
docker build -t docker.io/{username}/kfserving-custom-model ./model-server
docker push docker.io/{username}/kfserving-custom-model
kubectl apply -f custom.yaml -n kfs # change the image name inside custom.yaml
# 
export INGRESS_HOST=$(kubectl get po -l istio=ingressgateway -n istio-system -o jsonpath='{.items[0].status.hostIP}')
export INGRESS_PORT=$(kubectl -n istio-system get service istio-ingressgateway -o jsonpath='{.spec.ports[?(@.name=="http2")].nodePort}')
#
MODEL_NAME=kfserving-custom-model
INPUT_PATH=@./input.json
SERVICE_HOSTNAME=$(kubectl get inferenceservice ${MODEL_NAME} -n kfs -o jsonpath='{.status.url}' | cut -d "/" -f 3)
#
curl -v -H "Host: ${SERVICE_HOSTNAME}" http://${INGRESS_HOST}:${INGRESS_PORT}/v1/models/${MODEL_NAME}:predict -d $INPUT_PATH
