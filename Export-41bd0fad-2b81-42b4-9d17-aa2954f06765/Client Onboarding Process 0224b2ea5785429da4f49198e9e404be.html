Motivations

One might ask : “Why do I need a client onboarding process?”.

The answer would be : “To have a data-driven, disciplined and scalable approach to delight our customers”.

Who

  • Customer success manager or project manager

What

  • Defines process and steps to maximize joint success of client and PacketAI

When

  • After a client has agreed to a POC/POV or fulfilled initial payment

Why

  • To centralize all pieces of informations related to a client’s first weeks with PacketAI

Deployment Checklist

  • If client uses a Kubernetes version is older than the oldest version supported by PAI, we ask client to upgrade to a later version of his choice, but that is supported by PAI (eg: if the oldest version we support is 18, we ask a client running version 17 to upgrade at least to 18).
  • If client uses a Kubernetes version is more recent than the latest version supported by PAI, we should know it at least 7 business days before deployment, so we can arrange to internal testing. Else deployment date must be postponed (eg: if the latest version we support is 21, we ask a client running version 22 to let us know 7 days in advance to let us test).
