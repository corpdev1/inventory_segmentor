JIRA Ticket Creation

1)

Click on Create button for creating new JIRA ticket

2)

Select the Project:

  • bephor (BEP)

Select Issue Type:

  • Available
    • Task
    • Story
    • Epic
    • Bug

Summary:

  • Enter summary about the ticket
    • ex: Ruby service not detected in Topology service
    • ex: Anomaly detection not working for MYSQL

Description:

  • Enter full details about the ticket.
    • How to reproduce the issue
    • Possible Resolutions if known

3)

  • To Link the current ticket with the existing tickets we could use "Linked Issues"and "Issue"
  • Fix versions: to keep track of which tickets are released in each sprint we could use fix versions field, and later we could release this version and we could easily know which new features we added/bugs fixed ...
  • Assignee: you could assign the current ticket to yourself or for other people, if not could keep it to automatic.
  • Labels: we could assign multiple labels to current ticket, this helps to organise JIRA ticket better. We could use these labels to filter the tickets later.
  • Epic Link: Epic Link is used to organise the JIRA tickets in Scrum board. Select the appropriate Epic Link based on the ticket, Epic Links can be used across multiple projects

4)

  • Sprint: Select which sprint you will do this ticket, it can be current active sprint. If left blank the ticket will goto backlog.
  • Story Points: Estimated story Points for this ticket, similar to trello
  • Due date: due date for the current ticket
