kubeflow

Kubeflow is a stack of different component for ML workflow, and every component is loose coupled.

https://www.kubeflow.org/docs/started/kubeflow-overview/

some other details:

  1. support Multi-tenancy Jupyter Notebook on kubernete to do experiment

2. Ambassador: api gateway

3. Central Dashboard

4. Different framework for training

5. Hyperparameter Tuning:Katib

6. Pipeline: is a description of an ML workflow, including all of the components in the workflow and how they combine in the form of a graph. A pipeline component is a self-contained set of user code, packaged as a Docker image. support UI to see the pipeline workflow graph

https://towardsdatascience.com/build-your-data-pipeline-on-kubernetes-using-kubeflow-pipelines-sdk-and-argo-eef69a80237c

7. Model serving: Seldon, KFserving, can support customized model of python language

8. Logging, monitoring

9. support CRD(Custom Resource Definition) to define customized operator

Trouble Shoot

1.

Issue: knative failed to fetch ECR image information: unsupported status code 401; body: Not Authorized

Reason: knative revision controller fail to resolve ECR image to digest as revision

Solution: give ECR access via IAM to the pod knative-serving/controller

example ECR repository: https://eu-central-1.console.aws.amazon.com/ecr/repositories/kfserving-custom-model/permissions?region=eu-central-1

this repository has role `packetai-mgmt-cluster20201005064639334200000001` which has policy AmazonEC2ContainerRegistryPowerUser which allow to do ECR actions

then according to

https://github.com/knative/serving/pull/4084

https://github.com/uswitch/kiam

https://github.com/knative/serving/issues/1996

we can add 

annotations:
    iam.amazonaws.com/role: packetai-mgmt-cluster20201005064639334200000001

into pod knative controller using command: kubectl edit pod controller-5bf7fcf7dc-55gvc -n knative-serving

and add 

annotations:
    iam.amazonaws.com/permitted: ".*"

into related namespace using command: kubectl edit namespace knative-serving

other solution:

https://knative.dev/docs/serving/tag-resolution/
