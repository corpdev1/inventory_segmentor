Update 26.08.2021.

Example data with 20 metricsets

Request length for different intervals:

  • 1 day ⇒ 1440 data points ⇒ 1.3sec
  • 2 days ⇒ 2880 data points ⇒ 1.8sec
  • 3 days ⇒ 4320 data points ⇒ 2.25sec
  • 7 days ⇒ 10080 data points ⇒ 4.5sec

7 days of data(10080 data points) stats:

  • 18MB of data ⇒ compressed to 1.3MB for downloaded by the browser
  • 4.5sec total Becky request length ⇒ 3sec for elasticsearch requests + 0.5sec for download + 1sec for other
  • 2.5sec for Minima to render 10 metricsets ⇒ 7sec total
  • 10sec for Minima to render 20 metricsets ⇒ 14.5sec total

1 day of data(1440 data points) stats:

  • 1.3sec total Becky request length
  • 1.8sec for Minima to render 10 metricsets ⇒ 3.1sec total

Bottlenecks:

  • Elasticsearch has a default 10000 point per request restriction which can be changed
  • Highcharts boost performance feature has issues with markers which are essential for marking anomalies
  • Components could potentially have a lot more than 20 metricsets which will further lower performance

Next version:

  • Upgrade from 1 hour to 1 day timespan
  • Check performance and potential bottlenecks on real client data
  • Limit the max number of selected metricsets if there is an issue with rendering the charts on Minima
