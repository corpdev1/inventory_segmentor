Creating a user

  • Endpoint for user signup: https://api-dev.packetai.co/user
  • POST request(needs to have bearer token from Minima):
{
"email": "test@mail.com",
"family_name": "example",
"given_name": "example",
"preferred_username": "restricted_example",
"password": "packetai",
"roles": ["restricted"]
}
  • The role needs to contain restricted in the name in order to be not allow access to Becky/Minima
  • The role name must not contain more than 25 characters
  • The API will automatically add the infrastructureId prefix to the role
  • This will create the user with the roles {infrastructureId}-restricted and tenant-{infrastructureId}

Creating a restricted role

  • The role will have read access to only the selected components(by index patterns)
  • The role will have read access to the admin_tenant kibana tenant to be able to see all dashboards
  • The name of the role has to match the one for the created user(infrastructureId prefix included)
  • Cluster permissions:
    • indices:data/read/mget
  • Index permissions(chosen component indices + required admin tenant):
    • index-60a3b666eec9b06fc5e0aa9d-linux60a63130cf7da210ae2e6eb2-metric-dockerd703ee7b42306020 ⇒ read
    • index-60a3b666eec9b06fc5e0aa9d-linux60a63130cf7da210ae2e6eb2-log-dockerd703ee7b42306020 ⇒ read
    • .kibana_*_tenant{infrastructureId}* ⇒ kibana_all_read
  • Tenant permissions:
    • admin_tenant ⇒ Read only
  • Mapped users:
    • Users:
      • ${attr.jwt.sub}
    • Backend roles:
      • {infrastructureId}-restricted
