Importing dashboards

Importing a single dashboard to ODFE:

  • For each module the dashboard json file can be found in the official metricbeat/filebeat github repo (apache metricbeat example)
  • Before importing the dashboard all occurrences of the index patterns inside of the file need to be replaced with the standard PacketAI index patterns:
    • For Filebeat dashboards replace filebeat-* with index-*-log-*
    • For Metricbeat dashboards replace metricbeat-* with index-*-metric-*
  • The targeted endpoint to import the dashboards is https://kb.packetai.co:5601/api/kibana/dashboards/import (dev example)
  • To import the dashboards use the POST method with 2 cookies present security_authentication and security_preferences
  • These cookies should be obtained when logging in to Kibana and switching to the packetai tenant to Kibana
  • You can obtain them through the browser when you login and switch to the packetai tenant: inspect ⇒ Application ⇒ Cookies ⇒ https://kb.packetai.co:5601
  • By using the cookies of the packetai tenant you make sure that the dashboards end up in the right tenant on Kibana
  • You can do the same for the admin_tenant tenant or copy the entire packetai kibana tenant index to the admin_tenant kibana index (sometimes the indices have numbers probably for aliases at the end .kibana_750999216_packetai_3)
POST /_reindex
{
  "source": {
    "index": ".kibana_750999216_packetai"
  },
  "dest": {
    "index": ".kibana_-152937574_admintenant"
  }
}
  • In order to see the dashboard on Minima an update needs to be done on Becky to add the dashboard Id(can be found in the json file) to the proper subType: https://gitlab.packetai.co/bephor/becky/-/blob/master/src/services/dashboard/constants.ts

Importing all dashboard in a new ODFE:

  • Make sure you are in the packetai tenant
  • In the Kibana management menu select Stack Management ⇒ Saved Objects
  • Click on import and import the dashboards ndjson file (updated 16.02.2022 added more outsourced kubernetes, added 3 new Kube dashboards 15.03.2022):
  • Repeat for the admin_tenant tenant or copy the entire packetai kibana tenant index to the admin_tenant kibana index
