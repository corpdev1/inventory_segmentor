#How to create an deployment using ECR and codepipeline

#Introduction

This documentation covers the CD using code pipeline. For this documentation we will show how to create a pipeline.

#Requirements

#Cloudtrails

  • Ensure that cloudtrail events are enabled, if not set follow the Enable Cloudtrails Tutorial by clicking here

#ECR Permissions

  • Ensure ECR permissions are set in order to let codepipeline pull content from ECR, if not set follow the ECR Permission Tutorial by clicking here

#Step 1 - Go to codepipeline page and click on create pipeline button

#Step 2 - Set the codepipeline parameters

You will need to have the aws iam:CreateRole permission in order to create the pipeline role

#Step 3 - Select a source

We will take a ECR source, you can create it by clicking the create referencial button.Then chose the input image that will be taken for the build.

#Step 4 - Select a codebuild generator

CodeBuild will handle the creation of artifact.It will provide a zip file for codedeploy that contains the following 3 files:

  • imagedefinitions.json (containing some information about the docker images from ECR)
  • appspec.json (containing application specification like subnets, security groups and others stuffs)
  • taskdef.json (A définition of the docker image machine inside with the ports the image and the network configuration)

In this step you will need to click in to go to editor

#Step 8 - Codebuild generator - Edit with the generator

There you will need to replace the code pre-filled in the generator.

Replace with the following code:

version: 0.2
phases:
install:
runtime-versions:
python: 3.7
build:
commands:
- REPOSITORY_URI=$(cat imageDetail.json | python -c "import sys, json; print(json.load(sys.stdin)['ImageURI'].split('@')[0])")
- IMAGE_TAG=$(cat imageDetail.json | python -c "import sys, json; print(json.load(sys.stdin)['ImageTags'][0])")
- echo $REPOSITORY_URI:$IMAGE_TAG
post_build:
commands:
- echo Writing image definitions file...
- printf '[{"name":"minima","imageUri":"%s"}]' $REPOSITORY_URI:$IMAGE_TAG > imagedefinitions.json
- printf '{"version":0.0,"Resources":[{"TargetService":{"Type":"AWS::ECS::Service","Properties":{"TaskDefinition":"arn:aws:ecs:eu-west-3:767498580550:task-definition/minima:1","LoadBalancerInfo":{"ContainerName":"minima","ContainerPort":3000},"PlatformVersion":"LATEST","NetworkConfiguration":{"AwsvpcConfiguration":{"Subnets":["subnet-0da6b1b10460b362a","subnet-02ae15d454fddf2b8"],"SecurityGroups":["sg-04e52405f190fed39"],"AssignPublicIp":"ENABLED"}}}}}]}' > appspec.json
- printf '{"executionRoleArn":"arn:aws:iam::767498580550:role/ecsTaskExecutionRole","containerDefinitions":[{"portMappings":[{"hostPort":3000,"protocol":"tcp","containerPort":3000}],"image":"767498580550.dkr.ecr.eu-west-3.amazonaws.com/minima:latest","essential":true,"name":"minima"}],"memory":"2048","taskRoleArn":"arn:aws:iam::767498580550:role/ecsTaskExecutionRole","family":"minima","requiresCompatibilities":["FARGATE"],"networkMode":"awsvpc","cpu":"1024"}' > taskdef.json
artifacts:
files:
- imagedefinitions.json
- taskdef.json
- appspec.json

Don't forget to replace the follogine informations with the needed ones

  • name : Has to be the name of your ecr instance in postbuild commands that create imagedefinition.json
  • taskDefinition: Has to point to a préviously created Task Definition inside ECS (appspec.json)
  • Subnets: Has to match with the same subnets as your service subnets (appspec.json)
  • SecurityGroups: has to be a valid sécurity group (appspec.json)
  • AssignPublicIp: Should be enabled or disabled (appspec.json)
  • port: has to match application port in (appspec.json) & (taskdef.json)
