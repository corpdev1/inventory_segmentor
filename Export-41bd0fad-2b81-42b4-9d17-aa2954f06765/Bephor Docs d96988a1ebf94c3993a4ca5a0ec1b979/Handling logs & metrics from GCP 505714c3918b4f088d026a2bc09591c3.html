Filebeat’s integration

We can use the pub-sub integration delivered by Filebeat (https://www.elastic.co/guide/en/beats/filebeat/current/filebeat-input-gcp-pubsub.html)

  • Create a Pub/Sub topic
  • Create a Logging Sink
    • To write a exclusion / inclusion filter : https://cloud.google.com/logging/docs/view/logging-query-language
  • Create a Service Account with SubPubs authorizations (view and edition)

Configuration to apply :

filebeat.inputs:
- type: gcp-pubsub
  project_id: my-gcp-project-id
  topic: vpc-firewall-logs-topic
  subscription.name: filebeat-vpc-firewall-logs-sub
  credentials_file: ${path.config}/my-pubsub-subscriber-credentials.json

  • Metrics → Gets metrics from
  • Storage → Gets storage global informations
