Dynatrace:

  • Log monitoring:
    • Configurable from 5-90 days for both SaaS and Managed. Specific files can be included/excluded.
    • For Dynatrace SaaS customers, log files are stored in Amazon Elastic File System in the zone where your Dynatrace environment resides.
  • Timeseries metrics:
    • 5 years for both SaaS and Managed with different granularity(1 min to 1 day intervals)
    • Cassandra storage
  • Davis®(AI causation engine for anomalies detection) problems and events:
    • 12 months for both SaaS and Managed
  • Other(Distributed trace and code insights, Requests and request attributes, Aggregated user action data...):
    • 10 - 35 days for SaaS, up to 365 for Managed

Datadog:

  • Logs:
    • Plan (pricing based)
    • Logging without Limits™ option to archive logs to users' S3
  • System metrics and agent integrations:
    • 15 months
  • Live containers and processes:
    • 36 hours
  • Traces
    • 15 days
    • 15 months for trace metrics

Logz.io:

  • Plan (pricing based)
  • 3, 7, 14, 30 or 45 days
  • Has an archive and restore option to store historical data to users' S3 or Azure Storage and restore back to a temporary account for analysis(article)
