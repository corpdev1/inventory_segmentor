Monitoring agent on client vms

Solutions:

  1. using filebeat/metricbeat
    1. Write packetai-server logs to /etc/packetai with log rotator
    1. Configure filebeat to forward the logs from this file to kafka topic: #infraid-agent-logs (include agent id in the message)
    1. Configure metricbeat to monitor the packeta-server process and forward them to kafka topic: #infraid-agent-metrics (include agent id in the message)
