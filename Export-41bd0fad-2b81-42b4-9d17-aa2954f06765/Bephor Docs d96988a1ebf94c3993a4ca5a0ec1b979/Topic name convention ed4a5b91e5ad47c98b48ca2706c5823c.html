Kube

Patterns

Topic name is constructed as below

for raw:

${infraID}-${clusterName}-(metric|log)-${componentID}-raw

for stashed:

${infraID}-${clusterName}-(metric|log)-${componentID}-stashed

for ml:

${infraID}-${clusterName}-(mlmetric|mllog)-${componentID}

Complex item

${componentID} = ${Namespace}-${ResourceType}-${ResourceName}

Regex

ItemDescriptionregex
infraIDHexadecimal string[a-f0-9]+
clusterNamelowercase characters[a-z]+
componentIDalphanumeric characters and hyphens[a-z0-9\-]+
Namespacealphanumeric characters and hyphens[a-z0-9\-]+
ResourceTypealphanumeric characters and hyphens[a-z0-9\-]+
ResourceNamealphanumeric characters and hyphens[a-z0-9\-]+

Python Regex

  • r"([a-f0-9]+)\-([a-z]+)-(metric|log)-([a-z0-9\-]+)-(raw|stashed)”
  • r"([a-f0-9]+)\-([a-z]+)-(mlmetric|mllog)-([a-z0-9\-]+)”

Example

622737b3a93c6c0012cc3ada-kubernetessprodcommon-metric-dedup-prod-sts-dedup-coal-trade-logistic-metric-003-kp-dedup-stashed

  • infraID : 622737b3a93c6c0012cc3ada.
  • clusterName : kubernetessprodcommon.
  • ComponentId : dedup-prod-sts-dedup-coal-trade-logistic-metric-003-kp-dedup
    • Namespace : dedup-prod
    • ResourceType : sts
    • ResourceName : dedup-coal-trade-logistic-metric-003-kp-dedup

Non-Kube

Patterns

Topic name is constructed as below

for raw:

${infraID}-${agentID}-(metric|log)-${componentID}-raw

for stashed:

${infraID}-${agentID}-(metric|log)-${componentID}-stashed

for ml:

${infraID}-${agentID}-(mlmetric|mllog)-${componentID}

Regex

ItemDescriptionregex
infraIDHexadecimal string[a-f0-9]+
agentIDalphanumeric characters[a-z0-9]+
componentIDalphanumeric characters, hyphens, underscore, dot[a-z0-9\-._]+

Python Regex

  • r"([a-f0-9]+)-([a-z0-9]+)-(metric|log)-([a-z0-9\-._]+)-stashed”
  • r"([a-f0-9]+)-([a-z0-9]+)-(mlmetric|mllog)-([a-z0-9\-._]+)”

Example

  1. 621f3570d6025900129ba96f-linux621f462d72087c001310a34e-log-mongodb846643dff543f472-stashed
    • infraID - 621f3570d6025900129ba96f.
    • AgendID - linux621f462d72087c001310a34e.
    • ComponentID - mongodb846643dff543f472.
  1. 621f3570d6025900129ba96f-linux621f462d72087c001310a34e-log-rabbitmq_rabbitmq-stashed
    • infraID : 621f3570d6025900129ba96f.
    • AgendID : linux621f462d72087c001310a34e.
    • ComponentID : rabbitmq_rabbitmq.
