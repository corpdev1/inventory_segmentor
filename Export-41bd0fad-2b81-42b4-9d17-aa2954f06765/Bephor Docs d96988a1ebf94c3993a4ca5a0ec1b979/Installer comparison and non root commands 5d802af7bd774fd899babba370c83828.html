How to run non root

As with filebeat, we could modify systemd service definition to change User=<user> to start as non root.

We would have to modify filebeat/metricbeat binaries and services accordingly (see Filebeat)

Filebeat

Filebeat by default runs as root.

How to run non root

https://www.elastic.co/guide/en/beats/libbeat/current/config-file-permissions.html

Modify start scripts to start from another user and also modify user/group to read/stat files, change to beat user (and change filebeat file permissions from owned by root and 0644 (rw-r--r--)

For systemd service definition set User=<user> (run systemctl edit)

Datadog

Runs agent as service

Documentation is here https://docs.datadoghq.com/agent/basic_agent_usage/ubuntu/?tab=agentv6v7

Latest agent is datadog-agent_7.27.0-1_arm64.deb deb is here https://apt.datadoghq.com/pool/d/da

This is how to unpack on mac OS:

brew install dpkg 
dpkg -x datadog-agent_7.27.0-1_amd64.deb .

Installer is about 500 LoC

Supervisord (part of Datadog) runs under root https://docs.datadoghq.com/integrations/supervisord/?tab=host It monitors the uptime, status, and number of processes.

Datadog uses root to access docker socket.

How to run non root

In supervisor.conf change to run as nobody and modify directory permissions accordingly.
