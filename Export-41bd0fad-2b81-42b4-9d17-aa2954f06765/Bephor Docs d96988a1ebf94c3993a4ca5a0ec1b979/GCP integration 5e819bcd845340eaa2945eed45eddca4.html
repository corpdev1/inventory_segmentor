Data collection(not built)

  • using metricbeat + filebeat as an independent agent with Emma, called AWS service
  • as first iteration, we consider GCP as an infra , in the future, we will consider a region as infra
  • user enters his GCP credentials on Minima and activates AWS monitoring
  • the credentials are sent to the aws service which activates the metricbeat GCP module
  • the GCP service gathers data and sends it to the rest of the regular pipeline
  • this data will follow the usual pipelines: insight pipeline directly to Elasticsearch and the ML pipeline to ML models

Data pipelines

  • GCP is treated as an infra
  • most GCP metricsets are treated as components and some are added to the GCP data center component
  • each component (storage, loadbalancing...) has only one metricsets and the GCP data center component has multiple general metricsets

Data representation (topology)

DataCenter:

  • GCP is a separate data center node

Network:

  • GCP load balancer are network equipment nodes
  • If there are no network components(load balancers) for hosts we show a virtual network node

Host:

  • If the end service (storage...) doesn't have a host we show a virtual host node
  • If the host with an installed PacketAI agent is an EC2 instance it is linked to it's AWS load balancer or to a virtual network node

Process:

  • Processes are virtual nodes (managed by AWS)

Service:

  • Managed services (storageS...) are represented as nodes

Metricsets(dashboards):

Supported:

Unsupported:

  • compute ⇒ has dashboard, add as individual service component
  • loadbalancing ⇒ has 3 dashboards, add as individual service component
  • metrics ⇒ has dashboard, add as individual service component
  • pubsub ⇒ has dashboard, add as individual service component
  • storage ⇒ has dashboard, add as individual service component

Filesets(dashboards):

Supported:

Unsupported:

  • audit ⇒ has dashboard, add to GCP data center component as one of the tabs
  • vpcflow
  • firewall

Issues:

  • No features have been built yet
  • GCP data center metrics/logs coming from multiple pipes(how to handle ML?)
  • Most metricsets use grouped data by technology which is not ideal for ML and should be separated
