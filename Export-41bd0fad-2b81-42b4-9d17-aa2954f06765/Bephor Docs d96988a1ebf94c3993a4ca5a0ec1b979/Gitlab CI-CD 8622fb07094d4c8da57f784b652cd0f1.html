  • The gitlab CI/CD pipeline file location: https://gitlab.packetai.co/all/code/-/blob/dev/.gitlab-ci.yml

For each pull requests has the following 4 jobs are triggered

  • accounts ⇒ npm install and npm build
  • becky ⇒ unit tests and npm build
  • minima ⇒ unit tests
  • microservices ⇒ unit tests , code coverage and building the binaries

After merging the PR to dev branch, the following jobs are triggered

  • accounts ⇒ npm install and npm build
  • becky ⇒ unit tests and npm build
  • minima ⇒ unit tests
  • microservices ⇒ unit tests , code coverage and building the binaries
  • containerize_dev ⇒ build docker images and push to aws ecr
  • deploy ⇒ build agent binaries (dev and staging) and update them to linux/installer repo

On merging dev branch to master branch, the following jobs are triggered

  • containerize_stable ⇒ build docker images and push to aws ecr

On creation of tags, the following jobs are triggered

  • containerize_stable ⇒ build docker images and push to aws ecr
  • deploy ⇒ build agent binaries (dev and staging) and update them to linux/installer repo

the following stages are missing

  • On creating of tag, update the tags in flux repo for all prod clusters
  • On creation of tag update the agent binaries
