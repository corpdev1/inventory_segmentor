Kibana visualizations metrics formatting

To change the format of a metric in a Kibana visualization there are a couple of steps as suggested in an official response on the elastic forum:

  • The format is set on a specific index pattern which can be selected by going to Managed ELK ⇒ Stack Management ⇒ Index patterns
  • After selecting the index pattern search for the metric and select the edit(pencil icon) option
  • For the selected example metric docker.memory.usage.total we can change the Format from Default(Number) to Bytes
  • The format change will effect all visualizations that use the selected index pattern index-*-metric-* and field docker.memory.usage.total

  • After all the updates are done on one client’s Managed ELK, we would then need to export the updated index patterns and manually import them to the rest of the clusters

Anomaly charts metrics formatting

  • The info of each metricset can be found in the exported fields section of metricbeat
  • Some of the fields have the format field defined(circa 25/94 for Docker, 2/133 for MySQL, 0/70 for PostgreSQL...), an example of a metricset with the defined format would be the docker.memory.usage.* fields
  • The implementation would look something like this:
    • We copy all of the supported integration fields to Becky that have the format field defined
    • When we create the chart metadata that is sent to Minima we add the format
    • The format is then used on the chart labels *anomaly charts were updated to this step
    • The format is potentially also used to scale down the chart values themselves for a better representation
