Follow steps in order

  1. start all staging instances (search staging)

2. Kafka:

  • connect to KAFKA-STAGING
  • cd kafka
  • docker-compose up -d

3. Logstash:

  • connect to LOGSTASH_STAGING. (with ubuntu user)

start logstash

  • cd code/logstash/
  • ../../varloader/logstash/dev.sh

stop logstash

  • cd code/logstash/
  • ../../varloader/logstash/dev_down.sh

4. Microservices:

  • Whitelist MS ec2 on DEBBY (for dev only)
    • Find DEBBY ec2 instance
    • Select the instance security group launch-wizard-53
    • Edit inbound rules and add MS dev ec2 instance ip
  • connect to instance microservices_staging (with ubuntu user)
  • cd code/microservices
  • sh ./start.sh {environment(dev/staging/prod}. (sh ./start.sh staging for staging infra)

5. Opendistro:

  • connect to OPENDISTRO - STAGING (with ubuntu as user)
  • sudo docker-compose start

7. Kubernetes EKS

Scaling down:

Go to: https://eu-west-3.console.aws.amazon.com/ec2autoscaling/home?region=eu-west-3#/details/eks-70b91bf3-a51a-9276-ff5c-0a7c471fadad?view=details

edit Group details and set Desired capacity to 0

Similarly do for the following autoscaling groups set the Desired capacity to 0:
