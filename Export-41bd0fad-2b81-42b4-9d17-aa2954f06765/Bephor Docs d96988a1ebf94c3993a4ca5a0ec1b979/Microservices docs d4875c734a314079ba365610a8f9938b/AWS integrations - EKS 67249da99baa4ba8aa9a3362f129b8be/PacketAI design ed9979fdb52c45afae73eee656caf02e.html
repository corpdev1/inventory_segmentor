UI/UX

To monitor a Kube cluster in PacketAI, user goes through the following steps:

  • on integration page, go to the integration card and follow setup instructions
  • activate the kube integration
  • the landing page for kube would be the topology showing the cluster(s) composition
  • when click on any node, metrics of the node show up in the bottom of the page
    • cluster node:
      • cpu, memory, disk, network IO
      • list of controllers and health of each
      • button to expand
    • node node:
      • cpu, memory, disk, network IO
      • number of pods and health of each
      • button to expand
    • deployment node:
      • cpu, memory, disk, network IO
      • button to expand
  • when a expand button is clicked
    • show more metrics
    • show logs chart

  • NOTE: when a pod node is clicked, if the pod runs a supported technology then the bottom window shows two tabs: one for basic pod metrics and the other for detailed techno metrics (and logs)
