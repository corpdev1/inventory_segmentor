Ingest Service

Ingest service aims to ingest data, do some pre-processing (compression and security → future features) on the logs then write to Kafka and S3.

All the AWS Event is sent to route {infrastructureID}/aws/events/logs with HTTP POST request:

  • this event is written to kafka topic: {infrastructureID}-aws-cloudwatch-logs
  • This event also written to S3 Bucket: {S3_Bucket_Name}AWS_Lambda/{infrastructureID}/logs

x. Introduction

The ingest is a service that aim to collect logs (raw, and stashed) and metrics passing through Kafka, in order to store every information in a S3 bucket.

It also receives data using a Amazon Lamda through an API endpoint, and dispatch the data to Kafka and inside the S3 bucket.

x. Inputs and outputs

Inputs

  • API Endpoints :
    • / Endpoint used to return a "hello" message.
    • /healthcheck Returns the health of the program, for the container used.
    • /{infraID}/aws/event/logs Endpoint made for the Amazon Lamda to receive data.
    • /{id}/aws/events/logs Endpoint to receive logs, outputs to Kafka ({infraID}-{kafkaTopicName}) and to S3 (AWS_Lambda/{infraID}/{s3Directory})
    • /{id}/aws/elb/{elb}/region/{region}/type/{type} Endpoint to ingest ELB logs, outputs to Kafka ({infraID}-aws.elb-log-{elbName}-raw) and to S3 (logs-{kafkaTopicName})
    • /{id}/aws/cloudtrail/logs Endpoint to ingest Lambda logs and forwards them to S3 (logs/kafkaTopicName) and to Kafka ({infraID}-aws.cloudtrail-log-all-raw
    • /aws/ecs/{infraID}/{clusterName} Endpoint to ingest ECS metrics to Kafka ({infraID}-aws.ecs.host-metric-{clusterName}-raw)
    • /webhook/{infraID}/{agentID}/fbPrefix/{componentID} Endpoint to ingest rollbar events, output to Kafka ({infraID}-agentID-log-{component}-raw)

)Outputs

  • S3 Bucket :
    • John/{infraID}/{componentID}/{logs||metrics} Raw logs received from the agent
    • Preprocessed/{infraID}/{componentID}/{logs||metrics} Stashed logs
    • AWS_Lambda/{infraID}/{componentID}/{logs||metrics} Data received from the Lamda, using the API endpoint.
  • Kafka Topics :
    • {infraID}-aws-cloudwatch-log

x. Running the Ingest Service

Available flags :

  • debugMode : Enable debug mode. Change the logger level from Info to Debug.
  • port : Precise a port for the ingest router
  • internalMode : Enable internal mode. Disable database writes.

Available environnement variables :

Required :

  • S3_BUCKET : Name of the bucket that should be used for S3.
  • AWSACCESSID : AWS AccessID
  • AWSSECRETKEY : AWS Secret
