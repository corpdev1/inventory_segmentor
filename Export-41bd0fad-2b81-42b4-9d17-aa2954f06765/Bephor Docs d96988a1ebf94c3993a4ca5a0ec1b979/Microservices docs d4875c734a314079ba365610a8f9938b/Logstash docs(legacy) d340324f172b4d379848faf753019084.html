For usage

Logstash configuration sources can be found at https://gitlab.packetai.co/elk/logstash

initial docker folder is got from https://github.com/spujadas/elk-docker

Important setting:

  • The kafka input of logstash should have the parameter: metadata_max_age_ms => "5000". This forces logstash to discover newly created topics matching our topics_pattern every five second. See: https://www.elastic.co/guide/en/logstash/current/plugins-inputs-kafka.html#plugins-inputs-kafka-topics_pattern

Typical error:

Sometimes Logstash failed to generate '*stashed' is because Elasticsearch service is refused to be connected, on the log part, logstash always retry to connect to ES to install template, and didn't continue the processing, so i think install template step is step before processing

Update 26th march 2021

Issue: when ES goes down, logstash cannot write data to ES (he keeps trying) and this blocks logstash from stashing data and writing it to stashed topics

Solution: separate the two operations (writing to ES and stashing) into two different logstash instances (logstash in single threaded) - this could solve other noticed issues on MAD
