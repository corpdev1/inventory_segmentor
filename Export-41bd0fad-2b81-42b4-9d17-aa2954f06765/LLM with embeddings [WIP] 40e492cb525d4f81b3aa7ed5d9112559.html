Opensource embeddings for logs

Embedding from OpenAI are expensive ($0.0004 / 1K tokens for Ada model). An alternative is to use opensource model which will cost only the management of the service.

In order to ensure that opensource model could replace OpenAI model for the task of embeddings, the following experiment has been conducted :

  1. Collect a list of logs (1000) with different templates (50)
  1. Get the embedding of these logs by different algorithm
  1. Give the embeddings to a clustering algorithm (Kmeans with 50 cluster) with cosine similarity
  1. Compute the homogeneity score of the clustering with the original embedding

The hypotheses is that if the embedding is specific enough, logs with same templates should be clustered together. Results are on the table below :

The results shows that for this set of logs we can achieve similar results with openai model (text-embedding-ada-002). Specially for the opensource model all-MiniLM-L6-v2 which was trained as sentence transformer for similarity

The embedding size for the opensource models are smaller (384 < 1536) which means less computation in general.
