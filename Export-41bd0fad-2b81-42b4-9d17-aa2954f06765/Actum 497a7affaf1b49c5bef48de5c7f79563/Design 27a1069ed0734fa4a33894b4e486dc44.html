Multilabel Classification Approaches :

  • Binary Relevance : consider each target as a separate binary classification problem
    • + Very easy to implement
    • - Doesn’t handle many tags (we need a model for each tag)

      → not scalable

  • Classifier chains : We construct Model A as a Binary Classification model using the input instances we try to predict just 1 of the Label as the output.
    • + Preserve correlation of tags
    • - Fails when number of tags is huge / useless when tags are not correlated

      → not scalable

  • Label Powerest : A Multi-class Classifier is trained on all unique label combinations found in the Data.
    • + Easy
    • - Fail when number of tags is huge

      → O(n!) so no

  • Deep Learning Approaches : Simply a sigmoid at the output layer

Output Tag

  • How many tags shall we cover ?
    • Many tags are created by user and are very useless (only few
    • Pareto of number of tags : =⇒ Around 10000 tags cover 95% of the tags
    • Impact Loss Function and Performance Metric ⇒ Hamming Loss / Micro F1-score for metric

  • How Tags are correlated ?
    • Tags co-occurences
  • Is there important and less important tags ?
    • Depends on the task

Input

  • Title Only
    • + Fastest / Less information
    • - Might be not very informative
  • Titile + Body :
    • + More informative
    • - Slower

      → definitely title and body

  • Title + Body + Answers :
    • + Contains enough information
    • - Might not have answer at the moment of prediction /Slower

ML Approach

  • Traditional ML :
    • + Faster
    • - Less performant / Could fail if number of tags is large
  • Deep ML :
    • + More performant / Could include sequence information (LSTM) + Could handle large number of tags (if used)
    • - Slower Prediction

2.2. Pipeline:

  1. Clean Title+Body text (remove html tags, remove remove links, ...)
    1. Follow the cleaning of DSE https://chunyang-chen.github.io/publication/SEthesaurusWordnet_TSE19.pdf (https://github.com/DunZhang/DomainSpecificThesaurus/blob/master/DST/datasets/CleanData.py)
    1. Concatenate Title&Body to construct a parallel text
  1. Train word embedding model (word2vec) with gensim to be able to vectorize words Follow this tutorial : https://www.kaggle.com/pierremegret/gensim-word2vec-tutorial with a lot of changes on hyperparameters
  1. Vectorize all the Title&Body cleaned text and save them into multiple arrays
    1. Used simple average at first place
    1. TODO : compute average of word embeddings weighted with IDF
  1. Search the top-10 similar vector whenever title&body are provided
    1. MAP : Compute the cosine the similarity between the Vector and all the arrays → select the top-10 similar vectors
    1. REDUCE : Compute the top-10 similar vector on the list of top-10s of all arrays
    1. SELECT : Match the similar vectors to their corresponding Title&Body
