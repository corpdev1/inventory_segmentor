Transformations:

Reads from alerts collection, ⇒ transformation ⇒ insert into issues collection

The idea as follows:

  • WE will read alerts collection by notifiedAt. descended by notifiedAt
  • We transform the documents from alerts collection into issues collection json format
    • The following values need to update from the collection
    • we fetch matching template_id , topic and template from lad_templates in ml database by using triggerBy in alerts collection
    • We will map template to detectionAnomalyType : sample documents from lad_templates collection
