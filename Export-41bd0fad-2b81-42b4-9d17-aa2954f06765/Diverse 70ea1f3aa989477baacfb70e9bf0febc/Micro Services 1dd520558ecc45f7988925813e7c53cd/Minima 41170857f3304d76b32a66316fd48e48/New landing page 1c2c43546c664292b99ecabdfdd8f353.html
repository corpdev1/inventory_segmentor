Create Tabs: user could add multiple tabs on the landing page, based on his requirements/dashboards

Basic workflow:

  • Create an options page where the user will set up the landing page dashboards
  • Enable the user to add multiple dashboards as tabs by submitting their ID from managed ELK
  • After the user sets up the landing page it is added to the menu
  • It consists of custom or prebuilt Kibana dashboards that are embedded in Minima and separated in tabs
