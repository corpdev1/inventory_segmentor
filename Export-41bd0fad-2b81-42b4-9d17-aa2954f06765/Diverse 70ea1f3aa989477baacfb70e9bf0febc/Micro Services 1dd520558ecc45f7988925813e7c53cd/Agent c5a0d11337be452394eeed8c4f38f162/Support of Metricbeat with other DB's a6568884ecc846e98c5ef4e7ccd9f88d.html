Support of Metricbeat with other DB's

Logstash supported outputs

  • The following output plugins are supported by Logstash (https://www.elastic.co/guide/en/logstash/current/output-plugins.html)
  • As metricbeat generates document based metrics, we need to have DB's which support this. this limits the DB's that could support(NoSQL looks good).
  • Another limitation is logstash supported output formats, it has few DBs support.
  • Our selection critieria should be: 1) it should be scalable 2) ca we host this DB 3) Does it suport metricbeat collected metrics in json format ?
