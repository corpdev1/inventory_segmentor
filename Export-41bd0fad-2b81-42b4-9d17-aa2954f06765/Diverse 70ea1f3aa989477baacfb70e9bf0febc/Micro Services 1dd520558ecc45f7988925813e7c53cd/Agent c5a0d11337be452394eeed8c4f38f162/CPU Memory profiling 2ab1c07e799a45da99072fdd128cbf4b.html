CPU/Memory profiling

4/06/2021

how to reproduce

Add somoething like this in the main code you want to profile: 

fdcpu, err2 := os.Create("/tmp/cpu.prof")
        if err2 != nil {
                panic(err2)
        }
        defer fdcpu.Close()
        if err := pprof.StartCPUProfile(fdcpu); err != nil {
                panic(err)
        }
        defer pprof.StopCPUProfile()

        fdmem, err3 := os.Create("/tmp/mem.prof")
        if err3 != nil {
                panic(err3)
        }
        defer fdmem.Close()
        runtime.GC()
        defer func() {
                if err := pprof.WriteHeapProfile(fdmem); err != nil {
                        panic(err)
                }
        }()

execute the following command to have informations about the profiling: 

go tool pprof -http localhost:8080 mem.prof
go tool pprof -http localhost:8080 cpu.prof
