Metric Data transformation

Input raw data spec:

  1. topio name should be (ml.)?([a-f0-9]+)-([a-z 0-9 \- .]+)-metric-([a-z 0-9 \- . _]+)-raw for logstash kafka pipeline, and (es.)?([a-f0-9]+)-([a-z 0-9 \- .]+)-metric-([a-z 0-9 \- . _]+)-raw for logstash es pipeline
  1. message should have field: [@metadata][beat] == "metricbeat"
  1. field value if no numeric value, logstash will not generate data to stashed topic
  1. raw topic contains @timestamp , this is beat timestamp
    1. stashed topic timeS = @timestamp //10
    1. stashed topic @timestamp is logstash event output timestamp
    1. stashed topic consumerRecord.timestamp is kafka message ingestion timestamp
    1. ES index @timestamp use raw topic @timestamp

General Transformation:

Agg by "%{infraID}-%{agentID}-%{compoID}-%{timeS}"

different topic type spec:

  1. logical component of orchestrator

pattern: infraid-docker-metric-componentid-raw

ex: 6040a96cdcc614001153fc55-docker-metric-rabbitmqqueue_rabbitmq-raw

input:

[event][module]: docker, rabbitmq

partitions: number=1

no containers field(map between componentID and containerID)

Transformation:

subject <= [container][id] or [docker][info][id] if dataset == docker.info or [docker][event][id] if dataset == docker.event

timeS = @timestamp //10

agg by "%{infraID}-%{agentID}-%{compoID}-%{timeS}"

output:

index-#{infra}-#{agent}-metric-#{compoID}

#{infra}-#{agent}-metric-#{compoID}-stashed

mad metricname = "|".join([subject, dataset, metric,])

2. normal docker daemon topic

ex:

input:

[event][module]: docker

containers field(map between containerID and dockCompoID)

Transformation

subject: [container][id] or [docker][info][id] if dataset == "docker.info" or [docker][event][id] if dataset == "docker.event"

timeS = @timestamp //10

for all metrics, agg by %{infraID}-%{agentID}-%{compoID}-%{timeS}

in same time,

agg for each different container component id by %{infraID}-%{timeS}-%{[@metadata][docker_compo_id]}

output:

index-#{infra}-#{agent}-metric-#{compoID}

#{infra}-#{agent}-metric-#{compoID}-stashed

#{infra}-#{agent}-metric-#{dockCompoID}-stashed

mad metricname = "|".join([subject, dataset, metric,])

3. host system topic

input:

[event][module]: "system"

output:

index-#{infra}-#{agent}-metric-#{agent}

#{infra}-#{agent}-metric-#{agent}-stashed

additional case:

for case: dataset==system.process and has field [components]

name = event.get('[process][name]') compos = event.get('[components]') thisCompo = compos[name]

ex:

event=

{"components":

{

"packetai-server":"packetai349f3db3ddc0a5e2",

"python":"python77e8257e09faeedd"

},

"process": {"name":"packetai-server"},

"event":{"dataset":"system.process"},

}

output: #{infra}-#{agent}-metric-#{thisCompo}-stashed

4. component directly on infra/agent

input:

[event][module]: module of this component

output:

index-#{infra}-#{agent}-metric-#{compoID}

#{infra}-#{agent}-metric-#{compoID}-stashed

output:

index-#{infra}-#{agent}-metric-#{compoID}

#{infra}-#{agent}-metric-#{compoID}-stashed
