Merge/Fusion

For multiple documents we can merge the different fiels in different documents by bucket/interval of time

example:

we have a document containing cpu metrics

{
	@timestamp: "10:10:05"
	cpu: {
		metric_one: 1
		metric_two: 2
	}
}

we have a document containing memory metrics

{
	@timestamp: "10:10:07"
	memory: {
		metric_one: 3
		metric_two: 4
	}
}

we can then create a document merging the previous ones in an interval of 10 sec

{
	@timestamp:"10:10:00"
	cpu: {
		metric_one: 1
		metric_two: 2
	}
	memory: {
		metric_one: 3
		metric_two: 4
	}
}

raw evaluation

for 10 metric sets (cpu ,memory, disk, network, etc ....) every 10 sec over 30 days with one metric set by document

we have roughly 10 metrics sets * 6 measures in one minute * 60 minutes * 24 hours * 30 days = 2592000 documents

by merging by buckets of 10 secs we divide by 10 the number of ducuments

Roll up

For a number of documents created every 10 sec over 4 weeks we can reduce the number of documents by reducing the interval of available by scale of looking query time

dummy example:

for documents with a timestamp < 1 day we keep them

for documents with 1 day < timestamp < 1 week, we aggregate them by interval of 1 minute

for documents with 1 week < timestamp < 4 weeks, we aggregate them by interval of 10 minutes

raw evaluation

for a dataset of 1 document every 10 sec over 28 days (4 weeks): we have 6 documents by minute * 60 minutes * 24 hours * 30 days: 241920

timestamp < 1 day : before 8640 → after: 8640

1 day < timestamp < 1 week: before: 51840 → after: 8640

1 week < timestamp < 4 weeks: before: 181440 → after: 3024

total: before: 241920 → after: 20304

result : 11x reduction

Combining merge + roll up

with examples provided above

10 x reduction with merge

11 x reduction with roll up

result: 110 x reduction

Flattening

Flatten documents can help some query engines to have quicker aggregation

For a document with multiple level of nesting, for example with the following document

{
	@timestamp: "10:10:00"
	cpu: {
		metric_one: 1
		metric_two: 2
	}
	memory: {
		metric_one: 3
		metric_two: 4
	}
}

we can flatten into a new document: 

{
	@timestamp: "10:10:00"
	cpu.metric_one: 1
	cpu.metric_two: 2
	memory.metric_one: 3
	memory.metric_two: 4
}
