Engineering Test Cases - Checklist

Purpose of this is to make sure we internally are confident (and have checked) to the best of our abilities 80% of the use cases we expect to see at clients premises.

Definition of an edge case: Occurence < 1/10000

General Checklist

Agent/Microservices:

  • Documentation
  • Unit test coverage - 60-80%? To make sure we know when we add stuff (features) most things would work.
  • Block of tests i.e Integration Tests ?
  • Total expected test coverage ? And KPIs to follow progress.

Open distro:

  • Multi tenancy
  • Security
  • Dashboards

Infrastructure:

  • Logstash/Kafka etc

Per technology we check the following

Agent: Service and App Discovery

  • App inside a container
  • App outside a container
  • 2 apps in a container

Agent: Core

  • Machine restarts
  • Service/App restarts
  • Agent restarts
  • Static component ids

Technology Types:

  • Details of tech - Ruby app with gollium, rails, tmux etc etc etc
  • Version numbers - list all for each technology
