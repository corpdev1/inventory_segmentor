Minima:

  • On Agent installation page we will have the following instructions.
sudo BRANCH="dev" PAI_API_KEY="5d8c7a61c91008148894cc84" X_PAI_TOKEN="API Token" APIDEVURL="https://api-dev.packetai.co" bash -c "$(curl -L -H'X-PAI-TOKEN: api-token' $APIDEVURL/installers/agent/setup.sh)"
  • X_PAI_TOKEN will generate on Becky and store into Mongodb.
  • WE will store this information(token, URL, API key etc...) into our configuration on /etc/packetai/config

Becky Endpoints:

  • /installer/agent/{filename}
    • We will have S3 bucket location (environment variable) where we could download this filename
    • AGENT_BINARY_PATH = s3://dev.packetai.co/installers/agent
  • Make sure we authenticate each requests for this endpoint based on API token
  • we could use http header X-PAI-TOKEN for authenication
    • ex: X-PAI-TOKEN: abc-dev
  • When we are sending curl request we could add this HTTP header:
    • ex: curl -H "X-PAI-TOKEN: abc-dev" https://api-dev.packetai.co/installer/agent/setup.sh

Installer / Updater script changes

  • Use Becky endpoint instead of Gitlab
  • Add the generated `X_PAI_TOKEN` token in the configuration file (in /etc/packetai/config)
  • Remove branch in configuration file
    • Configuration file contains
      • Token (for the auto-updater to download and check new versions)
      • API URL
      • InfraID
      • Version (for the auto-updater to compares versions)

Auto-updater changes

  • Add implementation to check the version and download update script from becky
  • Issue possible : Creating a new implementation for checking and downloading assets from Becky will not be compatible for the Gitlab installations.
    • Solutions :
      1. Implementing both GitLab and Becky integrations and use only one by
        1. Selecting using ENV variables (stored in the .service file)
        1. Selecting the integration using flags (like -use-becky or -use-gitlab)
        1. Selecting automaticaly by checking if there is a token stored in the configuration file
      1. Implementing only Becky integration but push binary only on S3
