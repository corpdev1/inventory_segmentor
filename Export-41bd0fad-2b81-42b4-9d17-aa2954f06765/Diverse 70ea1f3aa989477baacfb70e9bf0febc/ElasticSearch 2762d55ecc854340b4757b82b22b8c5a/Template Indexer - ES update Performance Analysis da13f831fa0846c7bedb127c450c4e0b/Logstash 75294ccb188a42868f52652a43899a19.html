MIMO

We subscribe to multiple topics and parse them in the same pipeline, then output them in the same pipeline.

In es output, the fact is that the consuming and output speed will be decreased significantly if we subscribe to multiple topics and send them in the same es pipeline.

e.g.

Way 1: one logstash_es

subscribe to topic1, topic2 in the same input pipeline

output to es index index-topic1 index-topic2 through the same output pipeline

Way 2:

two logstash_es

one subscribe to topic1

one subscribe to topic2

one output to es index index-topic1

one output to es index index-topic2

Way 1’s the consuming speed is slower than Way 2’s sum

Input topics and output indices inside the same logstash pipeline:

Index rate max 4k * 3

e.g. two large topics are subscribed in the same logstash es (one logstash es with two large topic)

reduced ingest rate and unbalanced ingest

around 5.8k total ingest rate, 4.5k + 1.3k ☹️

Input topics and output indices inside different logstash pipeline:

two large topic are subscribed in separated logstash pipeline: (two logstash es, each takes care of only one topic):

12k total ingest rate, 6k each

Suggestion: separate input & output in different bulk insert pipeline rather than mix them together
