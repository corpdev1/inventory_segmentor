Indexing Rate

As es suggests when we do bulk insert, we should disable the replication, use more shards and increase the refresh rate.

In our case, we have three data nodes, we could dispatch the load by using three shards and set them evenly into two data nodes.

We can create the index with the following config when we do bulk insert

{
  "settings": {
    "index": {
			"number_of_shards": 3,
      "refresh_interval": "30s",
      "number_of_replicas": 0
    }
  }
}

Once the daily insert is done, we can add replicas.
