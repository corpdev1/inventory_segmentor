ElasticSearch Debug

Check the cluster status in Kibana:

GET _cluster/health
GET _cluster/health?level=indices
GET /_cluster/allocation/explain
GET /_cat/indices
GET /_cat/thread_pool/search?v&h=host,name,active,rejected,completed

if there are unassigned shards then we need to reroute them:

POST _cluster/reroute?retry_failed=true

Forcemerging:

POST /index-*/_forcemerge?max_num_segments=1

Reindexing:

POST _reindex
{
  "source": {
    "index": "index-6040a96cdcc614001153fc55-linux6040f7e73a9e9f0012cec090-metric-dockerc3fb5b8782cdbf02"
  },
  "dest": {
    "index": "index-6040a96cdcc614001153fc55-linux6040f7e73a9e9f0012cec090-metric-dockerc3fb5b8782cdbf02-backup"
  }
}

Reroute indexes from one node to another node:

POST /_cluster/reroute
{
  "commands": [
    {
      "move": {
        "index": "index-6040a96cdcc614001153fc55-linux6040eafa3a9e9f0012cebfd4-metric-dockere547f5f96877c0f3", 
        "shard": 0,
        "from_node": "opendistro-opendistro-es-data-2", 
        "to_node": "opendistro-opendistro-es-data-1"
      }
    }
  ]
}

Update refresh interval:

PUT /index-*/_settings
{
  "index" : {
    "refresh_interval" : "10s"
  }
}

Delete documents from ES index:

POST index-6040a96cdcc614001153fc55-linux604b83a14c58ea0011d6220f-metric-mysql6d7613c72a46df40/_forcemerge?only_expunge_deletes=true&flush=true

Explain:

GET /_cluster/allocation/explain

Assign primary shard to node

POST /_cluster/reroute
{
"commands": [
{
"allocate_stale_primary": {
"index": "index-6040a96cdcc614001153fc55-docker-metric-nginxappsmith_appsmith-nginx",
"shard": 0,
"node": "opendistro-opendistro-es-data-5",
"accept_data_loss": true
}
}
]
}

Remove data from node

PUT _cluster/settings
{
  "transient" :{
      "cluster.routing.allocation.exclude._ip" : "IP1,IP2,IP3"
   }
}
