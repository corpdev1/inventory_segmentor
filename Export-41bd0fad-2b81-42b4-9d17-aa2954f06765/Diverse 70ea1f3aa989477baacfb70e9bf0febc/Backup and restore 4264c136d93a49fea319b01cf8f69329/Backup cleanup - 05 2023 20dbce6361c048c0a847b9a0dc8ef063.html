Current backup methods

MongoDB

The microservice has 3 differents scripts that could be used in different services, for each purposes.

  • Backup : Using mongodump, create a complete dump of the mongodb database, named with the current time, and store it directly to S3.
  • Watch : Retrieve the list of backups from S3 where the last modification date is older than 5 hours, and delete every backups from S3.
  • Restore : Using mongorestore, restore from a given filename a backup.

Potential issue : The watch script does not take in consideration the previous backups. I think if the backup script does not work for any reason, the watch could delete every previous backups.
