Kafka upgrade with Docker Volume Backup

Useful link

https://cwiki.apache.org/confluence/display/ZOOKEEPER/Upgrade+FAQ

https://docs.confluent.io/platform/6.2.2/installation/configuration/broker-configs.html

Useful command to check broker version with latest label

sudo docker image inspect --format '{{json .}}' "confluentinc/cp-kafka"

Backup from container volume

check the command in section: Check the status of the zookeeper

mkdir -p /home/ubuntu/backup
# you need to find the leader of the zookeeper by checking their status one by one 
sudo docker run --rm --volumes-from kafkaconf_zk3_1 -v /home/ubuntu/backup:/backup ubuntu tar cvf /backup/backup.tar /var/lib/zookeeper

Download and Add Snapshot to zookeeper

mkdir -p /home/ubuntu/backup
curl https://issues.apache.org/jira/secure/attachment/12928686/snapshot.0 -o /home/ubuntu/backup/snapshot.0
# copy file into original zookeeper's volume 
# need to be done on each zk
sudo docker run --rm --volumes-from kafkaconf_zk1_1 -v /home/ubuntu/backup:/backup ubuntu cp /backup/snapshot.0 /var/lib/zookeeper/data/version-2

Upgrade Zookeeper

Following step should be repeated on each zookeeper. Leader should be operated last

Add new env config for zookeeper 

image: confluentinc/cp-zookeeper:6.2.2
# need to be removed after the roll update
ZOOKEEPER_SNAPSHOT_TRUST_EMPTY: 'true'
KAFKA_OPTS: '-Dzookeeper.4lw.commands.whitelist=*'

Add write access to the data folder

# assign access for write 
sudo docker run --rm --volumes-from kafkaconf_zk1_1 -v /home/ubuntu/backup:/backup ubuntu chmod -R  a+w /var/lib

Restart the zookeeper

# make sure you are under the folder /Kafkaconf
sudo docker-compose up -d

Check the status of the zookeeper

# if 3 is leader, expect value to be leader, 2, 2
# need to change the port per zookeeper: 
# ports by id 1, 2, 3: 52181, 62181, 63181
echo mntr | nc localhost 63181 | grep zk_server_state
echo mntr | nc localhost 63181 | grep zk_synced_followers
echo mntr | nc localhost 63181 | grep zk_followers

Remove the env var and restart again

ZOOKEEPER_SNAPSHOT_TRUST_EMPTY: 'true'

Upgrade broker

Check active controller

exec into zookeeper and run the following command to see the active controller broker, the broker should be updated as the last one:

# exec into zk2 so port is 62181
zookeeper-shell localhost:62181 get /controller

#result: {"version":1,"brokerid":3,"timestamp":"1643885127527"}
# update broker 3 as the last one

Add write access to the data folder

# suspend the broker for data access update
sudo docker stop <BROKER_NAME>
# assign access for write for all users
sudo docker run --rm --volumes-from <BROKER_NAME> ubuntu chmod -R  a+w /var/lib

# upgrade
sudo docker-compose up -d <BROKER_NAME_IN_DOCKER_COMPOSE>
