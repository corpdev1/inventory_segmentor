AKS Failed Volume & Node

When the spot instance is in failed status, it would block the pv from detaching. So each time new pod schedule from the troubabled spot instance node to a new node would cause pvc attach problem.

To avoid that, u need to drain & delete the node

kubectl get no
# get a list of nodes to find the vmss id

Go to azure → all resources → search the vmss name (e.g. machine called aks-packetaispot-30530431-vmss00000n in k8s, u search 30530431) → find failed machine name → find the node name in k8s 

k describe no aks-packetaispot-30530431-vmss00001r | grep ProviderID
# azure:///subscriptions/074e09e3-83fc-4aee-8762-a8ac0a421767/resourceGroups/mc_stage-rg_stage-aks_westeurope/providers/Microsoft.Compute/virtualMachineScaleSets/aks-packetaispot-30530431-vmss/virtualMachines/63

# use the /subscriptions/... to delete the instance

You need to change the value aks-packetaispot-30530431-vmss/virtualMachines/40 to be the machine’s identifier

az vm delete --ids /subscriptions/074e09e3-83fc-4aee-8762-a8ac0a421767/resourceGroups/MC_stage-rg_stage-aks_westeurope/providers/Microsoft.Compute/virtualMachineScaleSets/aks-packetaispot-30530431-vmss/virtualMachines/40
