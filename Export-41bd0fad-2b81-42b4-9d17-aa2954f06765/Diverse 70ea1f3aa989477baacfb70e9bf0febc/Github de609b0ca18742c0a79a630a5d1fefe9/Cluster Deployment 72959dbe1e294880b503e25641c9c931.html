Cluster Deployment

GCP create new Project:

  • on google cloud create new project, e.g. packetai-clientname
  • ask @rama to enable billing on the new project using account hardik-billing-account
  • increase the cpu quota. https://console.cloud.google.com/iam-admin/quotas

    by default it is 24cpu, but we need more :)

    N2 CPUS in region: europe-west3

    U have to enable the compute engine first to see the quotas, or create the empty cluster first.

Kafka cluster deployment:

  • Create new branch on https://github.com/PacketAI/kafkaconf using github action, use base branch called gitactions
  • OPTIONAL: please check the cert by running the following script, if cert and key do not match you will see a diff. If there is a diff ,ask @rama :). 
openssl x509 -noout -modulus -in consumer.client.cer.pem | openssl md5 > /tmp/crt.pub
openssl rsa -noout -modulus -in  consumer.client.key.pem | openssl md5 > /tmp/key.pub
diff /tmp/crt.pub /tmp/key.pub


openssl x509 -noout -modulus -in producer.client.cer.pem | openssl md5 > /tmp/crt.pub
openssl rsa -noout -modulus -in  producer.client.key.pem | openssl md5 > /tmp/key.pub
diff /tmp/crt.pub /tmp/key.pub
  • Run this github action: https://www.notion.so/packetai/Deploy-Kafka-on-GCP-c0ce7246c2d349398a61c23a4ea55650

GKE cluster deployment:

  • Check this instruction page: Create GKE cluster

Create flux configuration for new cluster

  • flux repo check out to harfang branch and create a new branch newclustername and run the command to create a new cluster

./create_cluster_config.sh newclustername harfang

  • Wait the k8s cluster creation
  • check this page: Deploy fluxcd on GKE k8s
